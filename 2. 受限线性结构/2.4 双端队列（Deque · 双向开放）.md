## 📌 核心概念

双端队列是允许在**队头、队尾两端同时进行插入和删除操作**的特殊队列，是栈和队列的结合体，灵活性远高于普通队列。

### 1. 核心操作

- 队头入队、队头出队
- 队尾入队、队尾出队
- 查队头元素、查队尾元素、判空、判满

### 2. 常见分类

- **输入受限双端队列**：仅允许一端进行插入操作，两端均可删除
- **输出受限双端队列**：仅允许一端进行删除操作，两端均可插入

### 3. 典型应用场景

- 滑动窗口最大值 / 最小值问题
- 回文字符串判断
- 操作系统任务调度
- C++ STL 中 `deque` 容器的底层实现

## 🔑 一、顺序实现（循环数组）

基于循环数组实现双端队列，核心差异在于 **`l` 和 `r` 指针的初始指向与移动规则 **，共有两种主流方案。

### ⚖️ 两种指针方案对比（核心重点）

| 方案          | 指针初始指向      | 左入队顺序     | 右入队顺序     | 左出队顺序            | 右出队顺序                 | 有效元素位置                                |
| :---------- | :---------- | :-------- | :-------- | :--------------- | :-------------------- | :------------------------------------ |
| **方案一（推荐）** | `l = r = 0` | 先移指针，后存数据 | 先存数据，后移指针 | `l = (l+1)%maxx` | `r = (r-1+maxx)%maxx` | 左：`data[l]`；右：`data[(r-1+maxx)%maxx]` |
| **方案二**     | `l = r = 0` | 先存数据，后移指针 | 先移指针，后存数据 | `l = (l+1)%maxx` | `r = (r-1+maxx)%maxx` | 左：`data[(l+1)%maxx]`；右：`data[r]`      |

> 💡 方案一是最通用、最符合直觉的写法，也是我们代码采用的方案。

### 💻 标准实现代码

```c
// 循环数组实现双端队列（Deque）
// 核心操作：初始化、左入、右入、左删、右删、左查、右查、判空、判满
// 指针规则：左先移动指针后存数据，右先存数据后移动指针
namespace Array_Deque {
	const int maxx = 10;    // 队列最大容量
	typedef struct Deque {
		int* data;          // 数据域
		int l, r;           // 左指针、右指针
		int sum;            // 元素计数器，用于判空判满
	}Deque;

	// 初始化双端队列
	Deque initDeque(void)
	{
		Deque q;
		q.data = (int*)malloc(sizeof(int) * maxx);
		q.l = q.r = 0;     // 初始：左右指针均指向0
		q.sum = 0;          // 元素计数为0
		return q;
	}

	// 左入队操作
	void Linsert(Deque* q, int x)
	{
		if (q->sum == maxx)
		{
			printf("Deque full, cannot enqueue.\n");
			return;
		}
		// 左指针循环左移，+maxx防止负数下标
		q->l = (q->l - 1 + maxx) % maxx;
		q->data[q->l] = x; // 存入数据
		q->sum++;           // 元素计数+1
	}

	// 右入队操作
	void Rinsert(Deque* q, int x)
	{
		if (q->sum == maxx)
		{
			printf("Deque full, cannot enqueue.\n");
			return;
		}
		q->data[q->r] = x; // 先存入数据
		// 右指针循环右移
		q->r = (q->r + 1) % maxx;
		q->sum++;           // 元素计数+1
	}

	// 左删队操作
	void Ldelete(Deque* q)
	{
		if (q->sum == 0)
		{
			printf("Deque empty, cannot dequeue.\n");
			return;
		}
		// 左指针循环右移，逻辑删除左端点
		q->l = (q->l + 1) % maxx;
		q->sum--;           // 元素计数-1
	}

	// 右删队操作
	void Rdelete(Deque* q)
	{
		if (q->sum == 0)
		{
			printf("Deque empty, cannot dequeue.\n");
			return;
		}
		// 右指针循环左移，+maxx防止负数下标，逻辑删除右端点
		q->r = (q->r - 1 + maxx) % maxx;
		q->sum--;           // 元素计数-1
	}

	// 查看左端点元素
	void Lfind(Deque* q)
	{
		if (q->sum == 0)
		{
			printf("Deque empty, cannot find.\n");
			return;
		}
		printf("The left element of the deque is %d.\n", q->data[q->l]);
	}

	// 查看右端点元素
	void Rfind(Deque* q)
	{
		if (q->sum == 0)
		{
			printf("Deque empty, cannot find.\n");
			return;
		}
		// r指向右端点的下一个位置，需回退一位，+maxx防止负数下标
		printf("The right element of the deque is %d.\n", q->data[(q->r - 1 + maxx) % maxx]);
	}

	// 测试函数
	void runTest(void)
	{
		Deque q = initDeque();

		Linsert(&q, 1);
		Linsert(&q, 2);
		Rinsert(&q, 3);
		Lfind(&q);
		Rfind(&q);

		Ldelete(&q);
		Lfind(&q);
		Rfind(&q);
		Rdelete(&q);
		Lfind(&q);
		Rfind(&q);
	}
}
```

## 🔑 二、链式实现（双向链表）

基于**带头结点的双向链表**实现双端队列，彻底解决容量限制问题，同样有两种主流指针方案。

### ⚖️ 两种指针方案对比（核心重点）

|方案|指针初始指向|左入队逻辑|右入队逻辑|有效元素位置|
|:--|:--|:--|:--|:--|
|**方案一**|`l` 指向真正左端，`r` 指向右端下一个结点|头结点前插入新结点|尾结点后插入新结点|左：`data[l]`；右：`data[r->pre]`|
|**方案二（推荐）**|`l` 指向左端前一个哨兵结点，`r` 指向真正右端|先给哨兵赋值，再新建哨兵|尾结点后插入新结点|左：`data[l->next]`；右：`data[r]`|

> 💡 方案二是我们采用的方案，核心巧思是**征用头结点存数据**，实现左入队零特判。

### 💻 标准实现：方案二（删首元结点版）

```c
// 带头结点的双向链表实现双端队列（Deque）
// 核心巧思：征用头结点存数据，左删保留哨兵，删最后一个元素时重置指针回初始状态
// 核心操作：初始化、左入、右入、左删、右删、左查、右查、判空
namespace Linked_Deque {
	typedef struct Node {
		int data;           // 数据域
		struct Node* pre;   // 前驱指针
		struct Node* next;  // 后继指针
	}Node;

	// 封装左右指针，简化传参逻辑
	typedef struct LinkDeque {
		Node* l;  // 左指针，指向当前待填充的哨兵结点
		Node* r;  // 右指针，指向最后一个数据结点
	}Deque;

	// 初始化空双端队列
	Deque* initDeque(void)
	{
		// 创建初始哨兵结点，前驱后继均置空
		Node* s = (Node*)malloc(sizeof(Node));
		s->pre = s->next = NULL;
		// 创建队列结构体，l、r均指向初始哨兵结点
		Deque* p = (Deque*)malloc(sizeof(Deque));
		p->l = p->r = s;
		return p;
	}

	// 左入队操作（巧思：直接给当前哨兵结点赋值，无需空队特判）
	void Linsert(Deque* q, int x)
	{
		// 1. 给当前待填充的哨兵结点赋值
		q->l->data = x;

		// 2. 创建新的待填充哨兵结点，放在最左侧
		Node* s = (Node*)malloc(sizeof(Node));
		s->pre = NULL;
		s->next = q->l;
		q->l->pre = s;

		// 3. 左指针左移，指向新的待填充哨兵结点
		q->l = s;
	}

	// 右入队操作（尾插法）
	void Rinsert(Deque* q, int x)
	{
		// 1. 创建新数据结点
		Node* s = (Node*)malloc(sizeof(Node));
		s->data = x;
		s->next = NULL;
		s->pre = q->r;

		// 2. 新结点链接到队尾
		q->r->next = s;

		// 3. 右指针右移，指向新的队尾
		q->r = s;
	}

	// 判断队空（l==r 表示空，逻辑自洽）
	bool isEmpty(Deque* q)
	{
		return q->l == q->r;
	}

	// 左删队操作（保留哨兵结点，删首元结点）
	void Ldelete(Deque* q)
	{
		if (isEmpty(q))
		{
			printf("Deque empty, cannot delete.\n");
			return;
		}

		// 1. 拿到要删除的首元结点
		Node* t = q->l->next;

		// 2. 调整指针，移除首元结点
		q->l->next = t->next;

		// 3. 【关键】若删除的是最后一个数据结点，重置r指针回哨兵
		if (t == q->r)
			q->r = q->l;

		// 4. 若队列非空，调整后继结点的前驱指针
		if (t->next != NULL)
			t->next->pre = q->l;

		// 5. 释放内存
		free(t);
		t = NULL;
	}

	// 右删队操作（删除尾结点）
	void Rdelete(Deque* q)
	{
		if (isEmpty(q))
		{
			printf("Deque empty, cannot delete.\n");
			return;
		}

		// 1. 拿到要删除的尾结点
		Node* t = q->r;

		// 2. 调整指针，移除尾结点
		q->r = t->pre;
		q->r->next = NULL;

		// 3. 释放内存
		free(t);
		t = NULL;
	}

	// 查看左端点元素（首元结点）
	void Lfind(Deque* q)
	{
		if (isEmpty(q))
		{
			printf("Deque empty, cannot find.\n");
			return;
		}
		printf("The left element of the deque is %d.\n", q->l->next->data);
	}

	// 查看右端点元素（尾结点）
	void Rfind(Deque* q)
	{
		if (isEmpty(q))
		{
			printf("Deque empty, cannot find.\n");
			return;
		}
		printf("The right element of the deque is %d.\n", q->r->data);
	}

	// 测试函数
	void runTest(void)
	{
		Deque* q = initDeque();
		//（内容重复略...）
	}
}
```

### ✨ 拓展优化：删哨兵版（学长推荐，更优）

**核心优势**：删除左端点时直接删除哨兵结点本身，**不需要判断是否是最后一个元素**，彻底消除特殊情况，代码更简洁。

```c
// 左删队操作（优化版：直接删除哨兵结点）
void Ldelete(Deque* q)
{
	if (isEmpty(q))
	{
		printf("Deque empty, cannot delete.\n");
		return;
	}

	// 1. 拿到要删除的哨兵结点
	Node* t = q->l;

	// 2. 左指针右移，指向原首元结点（新的哨兵）
	q->l = q->l->next;
	q->l->pre = NULL;

	// 3. 释放内存
	free(t);
	t = NULL;
}
```

### 📌 设计亮点总结

1. **左入队零特判**：直接给当前哨兵结点赋值，无需判断队列是否为空，逻辑丝滑高效。
2. **纯指针判空**：完全不需要 `sum` 计数器，靠 `l==r` 就能完美区分空队列和非空队列。
3. **删哨兵更优**：直接删除哨兵结点，彻底消除 “删除最后一个元素” 的特殊判断，代码更简洁，不易出错。

## 🔍 考研经典例题

### 例题 1（输出受限型）

**题目**：两端都允许入队，但是只允许在一端出队。入队顺序 a b c d e，要求全部入队后，再执行出队，以下哪个出队顺序不合法（）

A. b a c d e

B. d b a c e

C. d b c a e

D. e c b a d

**答案**：C

**核心规则与解题技巧**：

- 入队顺序固定：`a → b → c → d → e`，必须按顺序依次入队
- 入队方式：每个元素可选择队头入队或队尾入队
- 解题关键：双端队列仅能两端插入，**先入队的相邻元素必然保持相邻**，后入队的元素无法插入到已有元素中间。

**选项解析**：

- A、B、D：均可通过两端入队实现，合法。
- C：前两个入队的 a、b 必然相邻，但选项中 b 和 a 之间插入了 c，无法实现，不合法。

### 例题 2（输入受限型・408 同源考点）

**题目**：某输入受限的双端队列，允许在一端进行入队和出队，另一端仅允许入队。若入队序列为 1、2、3、4，下列不可能得到的出队序列是（）

A. 4 3 2 1

B. 4 2 1 3

C. 4 2 3 1

D. 4 3 1 2

**答案**：D

**简要解析**：

本题为输入受限双端队列：仅左端可入队 + 出队，右端仅可入队。

- A、B、C：均可通过合理的入队出队顺序实现，合法。
- D：出队 4、3 后，剩余队列是`[1,2]`，只能先出 2 再出 1，无法得到 1 2 的顺序，不合法。

## 📝 笔记重点

1. **指针方案是核心**：无论是顺序还是链式实现，`l` 和 `r` 指针的指向决定了所有操作的逻辑，必须牢记不同方案的规则。
2. **顺序实现推荐**：采用 “左先移后存，右先存后移”+`sum`计数器的方案，逻辑最清晰。
3. **链式实现推荐**：采用 “征用头结点存数据”+“删哨兵” 的方案，代码最简洁，无特殊判断。
4. **考研解题技巧**：输出受限双端队列的核心是 “相邻元素必然相邻”，可快速排除错误选项。
