### 📌 核心概念：什么是队列？

队列是只允许在一端插入、另一端删除操作的线性表。

- **队头 (Front)**：允许删除的一端。
- **队尾 (Rear)**：允许插入的一端。
- **空队列**：队列中没有任何数据。
- **核心性质**：**先进先出 (FIFO, First In First Out)**

---

### 🔑 两种主流实现方式

#### 1. 顺序队列（数组实现）

顺序队列基于数组 `data[maxx]` 实现，用 `front`（队头指针）和 `rear`（队尾指针）标记边界。

##### ✅ 1. 基础操作逻辑

- 入队：从队尾放入，`rear` 后移
- 出队：从队头删除，`front` 后移
- 判空：`front == rear`
- 判满：`rear == maxx`

##### ❌ 2. 致命问题：假溢出

`rear` 走到数组末尾，但前面因出队空出大量位置，却无法继续入队。

本质：线性数组无法复用空间，是顺序队列的设计缺陷。

---

# 💻 顺序队列核心代码实现

```c
// 普通顺序队列（线性数组实现，存在假溢出问题）
// 核心操作：初始化、入队、出队、查队头、查队尾、判空、判满
namespace Sequential_Queue {
	const int maxx = 10;    // 队列最大容量
	typedef struct {
		int* data;          // 数据域
		int front, rear;    // 队头指针、队尾指针
	}Queue;

	// 初始化顺序队列
	Queue initQueue(void)
	{
		Queue q;
		q.data = (int*)malloc(sizeof(int) * maxx);
		q.front = q.rear = 0;  // 初始：队头=队尾，空队列
		return q;
	}

	// 判断队满（rear到达数组末尾即满）
	bool isFull(Queue* q)
	{
		return q->rear == maxx;
	}

	// 入队操作
	void enqueue(Queue* q, int x)
	{
		if (isFull(q))
		{
			printf("Queue full, cannot enqueue.\n");
			return;
		}
		q->data[q->rear++] = x;  // 元素放入队尾，rear后移
	}

	// 判断队空
	bool isEmpty(Queue* q)
	{
		return q->front == q->rear;
	}

	// 出队操作
	void dequeue(Queue* q)
	{
		if (isEmpty(q))
		{
			printf("Queue empty, cannot dequeue.\n");
			return;
		}
		q->front++;  // 队头指针后移，逻辑删除
	}

	// 获取队头元素
	void getFront(Queue* q)
	{
		if (!isEmpty(q))
			printf("The front element of the queue is %d.\n", q->data[q->front]);
		else
			printf("Queue is empty, no front element.\n");
	}

	// 获取队尾元素
	void getRear(Queue* q)
	{
		if (!isEmpty(q))
			// 顺序队列 rear 不会为 0，无需取模，直接 rear-1 即可
			printf("The rear element of the queue is %d.\n", q->data[q->rear - 1]);
		else
			printf("Queue is empty, no rear element.\n");
	}

	void runTest(void)
	{
		Queue q = initQueue();

		enqueue(&q, 1);
		enqueue(&q, 2);
		enqueue(&q, 3);
		getFront(&q);
		getRear(&q);

		dequeue(&q);
		dequeue(&q);
		getFront(&q);
		getRear(&q);
	}
}
```

#### 2. 循环队列（解决假溢出）🔄

通过**取模 `% maxx`** 让数组逻辑上首尾相连，实现空间复用。

##### 1. 核心矛盾：空与满的判断

`front == rear` 既可以表示空，也可以表示满，必须区分。

常用方案：**牺牲一格法**（最简单、最通用）

- 牺牲一个数组位置，不存数据
- 判空：`front == rear`
- 判满：`(rear + 1) % maxx == front`

##### 2. 标准操作规则

- 初始化：`front = rear = 0`
- 入队：`rear = (rear + 1) % maxx`
- 出队：`front = (front + 1) % maxx`
- 队尾下标：`(rear - 1 + maxx) % maxx`（防负数越界）

---

# 💻 循环队列核心代码实现

```c
// 循环队列（牺牲一个空间判别队满）
// 核心操作：初始化、入队、出队、查队头、查队尾、判空、判满
namespace Circular_Queue {
	const int maxx = 10;    // 队列最大容量（实际可用 maxx-1）
	typedef struct {
		int* data;          // 数据域
		int front, rear;    // 队头、队尾指针
	}Queue;

	// 初始化循环队列
	Queue initQueue(void)
	{
		Queue q;
		q.data = (int*)malloc(sizeof(int) * maxx);
		q.front = q.rear = 0;  // 初始：队头=队尾，空队列
		return q;
	}

	// 判断队满（牺牲一格法）
	bool isFull(Queue* q)
	{
		return (q->rear + 1) % maxx == q->front;
	}

	// 入队操作
	void enqueue(Queue* q, int x)
	{
		if (isFull(q))
		{
			printf("Queue full, cannot enqueue.\n");
			return;
		}
		q->data[q->rear] = x;          // 新元素放入队尾
		q->rear = (q->rear + 1) % maxx; // 队尾指针循环+1
	}

	// 判断队空
	bool isEmpty(Queue* q)
	{
		return q->rear == q->front;
	}

	// 出队操作（仅移动指针，不释放元素）
	void dequeue(Queue* q)
	{
		if (isEmpty(q))
		{
			printf("Queue empty, cannot dequeue.\n");
			return;
		}
		q->front = (q->front + 1) % maxx; // 队头指针循环+1
	}

	// 获取队头元素
	void getFront(Queue* q)
	{
		if (!isEmpty(q))
			printf("The front element of the queue is %d.\n", q->data[q->front]);
		else
			printf("Queue is empty, no front element.\n");
	}

	// 获取队尾元素（注意防越界）
	void getRear(Queue* q)
	{
		if (!isEmpty(q))
			// +maxx 再取模，防止 rear=0 时出现负数下标，导致数组越界
			printf("The rear element of the queue is %d.\n", q->data[(q->rear - 1 + maxx) % maxx]);
		else
			printf("Queue is empty, no rear element.\n");
	}

	void runTest(void)
	{
		Queue q = initQueue();
		//（...内容重复略）
	}
}
```

### ⚖️ 顺序队列 vs 循环队列（对比总结）

|特性|顺序队列|循环队列|
|:--|:--|:--|
|**结构**|线性数组|逻辑循环数组|
|**溢出问题**|假溢出严重|无假溢出，空间充分利用|
|**判空**|`front == rear`|`front == rear`|
|**判满**|`rear == maxx`|`(rear+1)%maxx == front`|
|**指针移动**|只增不减|循环取模|
|**空间效率**|低|高|

---

### 🔍 关键补充：为什么不初始化 `front = maxx-1`？

很多同学会疑惑：

既然可以牺牲一格区分空满，那我初始设 `front = maxx-1，rear=0` 不行吗？

理论上可以调整规则：

让 `front` 和 `rear` **间隔 2 表示满，间隔 1 表示空**，也能实现功能。

但**工程与考试中几乎不这么用**，核心原因是：

- 这种写法会把简洁的 **间隔 0 为空、间隔 1 为满**
    
    强行变成 **间隔 1 为空、间隔 2 为满**，人为复杂化判断规则。
    
- 破坏了 `front == rear` 表示空队列的通用语义，极易造成理解歧义。
    
- 取模、判空、判满、取队尾等逻辑全部要重写，无任何收益，反而更容易出错。
    

因此循环队列**唯一标准初始化**：

`front = rear = 0`

---

### ⚠️ 循环队列：上溢与下溢（补充）

- **上溢（Overflow）**：队满时继续入队，无法存入数据。
- **下溢（Underflow）**：队空时继续出队，访问非法数据。

### ✅ 记忆口诀

- 满了再入 → 上溢
- 空了再出 → 下溢
- 循环队列仍会出现上溢（固定数组大小），但不会出现假溢出。

---

### 💡 重要细节补充

#### 1. 队尾为什么要 `+maxx` 再取模？

当 `rear = 0` 时，`rear - 1 = -1`，直接访问会数组越界崩溃。

`(rear - 1 + maxx) % maxx` 保证下标永远为正，安全合法。

#### 2. 队列的 “查看操作”

栈只有 `getTop`，队列对应有 `getFront` 和 `getRear`。

因为队列双端操作，教材不常强调，但实现中是必备功能。

---

### 📝 笔记重点

- 访问规则：队列是双端受限线性表，队尾入、队头出。
- 循环队列：用 `% maxx` 实现逻辑闭环，解决假溢出。
- 判空判满：牺牲一格法最简洁，`front==rear` 为空，`(rear+1)%maxx==front` 为满。
- 队尾安全访问：`(rear - 1 + maxx) % maxx` 避免负数下标越界。
