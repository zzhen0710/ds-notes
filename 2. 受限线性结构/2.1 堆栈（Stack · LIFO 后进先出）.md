### 📌 核心概念：什么是栈？

**栈**是只允许在**一端**进行插入或删除操作的线性表。

- **栈顶 (Top)**：允许操作的一端。
- **栈底 (Bottom)**：不允许操作的一端。
- **空栈**：栈中没有任何数据。

**核心性质**：**先进后出 (LIFO, Last In First Out)**

---

### 🔑 两种主流实现方式

#### 1. 顺序栈（数组实现）

利用数组 `data[maxx]` 实现，需关注**栈顶指针 `top`** 的两种定位逻辑：

- **top = -1**：top 直接指向栈顶数据，初始化空栈时为 -1。
- **top = 0**：top 指向栈顶数据的下一个位置，初始化空栈时为 0（此时 `top-1` 才是栈顶）。

#### 2. 链栈（链表实现）

利用**带头结点的单链表**实现，仅在表头（头结点之后）进行操作，无需判满（动态分配）。

# 💻 堆栈核心代码实现（顺序栈 & 链栈）


```c
#include<stdio.h>
#include<stdlib.h>
#include<stdbool.h>

// 限制线性结构——顺序栈的基本操作
namespace Sequential_Stack {
	const int maxx = 10;
	typedef	struct {
		int* data;
		int top;	// 栈顶“指针”
	}Stack;

	// 初始化空栈 (top=-1 策略)
	Stack initStack(void)
	{
		Stack s;
		s.data = (int*)malloc(sizeof(int) * maxx);
		s.top = -1;	// top指向栈顶，-1表示空栈
		return s;
	}

	// 判断栈满
	bool isFull(Stack* s)
	{
		return s->top == maxx - 1;
	}

	// 入栈
	void push(Stack* s, int x)
	{
		if (isFull(s)) {
			printf("Stack full, cannot push.\n");
		}
		else {
			s->data[++s->top] = x;
		}
	}

	// 判断栈空
	bool isEmpty(Stack* s)
	{
		return s->top == -1;
	}

	// 出栈 (仅移动指针，不清理数据)
	void pop(Stack* s)
	{
		if (isEmpty(s)) {
			printf("Stack empty, cannot pop.\n");
		}
		else {
			s->top--;
		}
	}

	// 获取栈顶元素
	void getTop(Stack s)
	{
		if (isEmpty(&s)) {
			printf("Stack empty, cannot get.\n");
		}
		else
			printf("The top element of the stack is %d.\n", s.data[s.top]);
	}

	void runTest()
	{
		Stack s = initStack();
		push(&s, 1);
		push(&s, 2);
		push(&s, 3);
		getTop(s);
		pop(&s);
		pop(&s);
		getTop(s);
	}
}

// 限制线性结构——链栈的基本操作
namespace Linked_Stack {
	typedef struct Node{
		int data;
		struct Node* next;
	}SNode, *LinkStack;

	// 初始化空栈 (带头结点)
	LinkStack initStack()
	{
		SNode* h = (SNode*)malloc(sizeof(SNode));
		h->next = NULL;
		return h;
	}

	// 入栈 (头插法)
	void push(LinkStack s, int x)
	{
		SNode* p = (SNode*)malloc(sizeof(SNode));
		p->data = x;
		p->next = s->next;
		s->next = p;
	}

	// 判断栈空
	bool isEmpty(LinkStack s)
	{
		return s->next == NULL;
	}

	// 出栈 (删除首元结点)
	void pop(LinkStack s)
	{
		if (isEmpty(s)) {
			printf("Stack empty, cannot pop.\n");
		}
		else {
			SNode* p = s->next;
			s->next = p->next;
			free(p);
			p = NULL;
		}
	}

	// 获取栈顶元素
	void getTop(LinkStack s)
	{
		if (isEmpty(s)) {
			printf("Stack empty, cannot get.\n");
		}
		else
			printf("The top element of the stack is %d.\n", s->next->data);
	}

	void runTest()
	{
		LinkStack s = initStack();
		push(s, 1);
		push(s, 2);
		push(s, 3);
		getTop(s);
		pop(s);
		pop(s);
		getTop(s);
	}
}

void main()
{
	/*Sequential_Stack::runTest();*/
	Linked_Stack::runTest();
}
```

### ⚖️ 顺序栈 vs 链栈（对比总结）

| 特性       | 顺序栈 (Sequential Stack) | 链栈 (Linked Stack)   |
| :------- | :--------------------- | :------------------ |
| **存储结构** | 数组 (Array)             | 链表 (Linked List)    |
| **空间分配** | 静态分配，**不易扩容**          | 动态分配，**灵活**         |
| **栈顶指针** | 整型变量 `top`             | 指针 `top`            |
| **判满条件** | `top == maxx - 1`      | 无需判满 (malloc 失败才会满) |
| **判空条件** | `top == -1`            | `s->next == NULL`   |
| **主要缺点** | 容量固定，易溢出               | 需处理指针，有链表开销         |

### ⚠️ 顺序栈：上溢与下溢（补充）

- **上溢（Overflow）**：栈已满（`top == maxx - 1`）时，仍执行入栈 `push` 操作，导致数据无法存入，是顺序栈容量固定的典型问题。
- **下溢（Underflow）**：栈已空（`top == -1`）时，仍执行出栈 `pop` 或取栈顶操作，尝试访问不存在的数据。



### ✅ 记忆口诀

- **满了再入 → 上溢**
- **空了再出 → 下溢**
- 链栈无**上溢**（动态扩容），但仍可能发生**下溢**。

### 🎯 栈的核心应用

#### 1. 历史记录与撤销

基于**后进先出**性质，实现操作的回溯逻辑，如编辑器的撤销操作、网页回退。

#### 2. 函数调用与递归 (Call Stack)

程序运行时的函数调用栈，递归的底层实现依赖栈保存现场。

#### 3. 卡特兰数 (Catalan Number) —— 栈的计数问题

**Q🔸：n 个元素进栈，有多少种不同的出栈顺序？**

A✅️：这是经典的卡特兰数应用场景。

**公式**：
$$ C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)!\,n!} $$

**含义**：它不仅描述出栈序列数，还对应**二叉搜索树形态数**、**括号匹配数**等组合数学问题。

#### 4. 内存中的堆栈 (Stack vs Heap)

操作系统中的**栈区**（Stack）用于存放函数参数、局部变量；**堆区**（Heap）用于动态内存分配，二者名字虽有重合但概念不同。

### 📝 笔记重点

1. **操作本质**：栈是对线性表的限制，核心在于**单一入口**的访问规则。
2. **`top` 指针**：是操作栈的灵魂，顺序表中注意 -1 和 0 位置的区别，链表中注意头结点的指向。
3. **无 NULL 陷阱**：链栈因使用头结点，避免了头指针为 NULL 的判断，逻辑更统一。
