### 📌 算法评价标准

算法是对某个问题的求解步骤，最终转化为可运行的代码。一个 "好" 的算法必须满足以下优先级：

1. ✅ **正确性**：能彻底解决问题，输出结果符合预期
2. 🛡️ **健壮性**：处理非法输入时不会崩溃，能给出合理提示
3. ⚡ **效率**：在满足前两个条件的基础上，追求**运行时间短**和**占用内存少**

### 💡 算法与复杂度核心思想

算法的好坏由**时间效率**和**空间效率**共同决定。

- 时间效率：执行速度越快越好
- 空间效率：占用内存越少越好

实际运行测速受硬件、环境、数据规模影响极大，因此我们必须使用**事前复杂度分析**，只看**执行次数的增长趋势**，用大 O 表示渐进复杂度。

复杂度只保留最高阶项，忽略常数、系数、低阶项，用来衡量算法随数据规模变大的性能趋势。

#### ⏳ vs 💾 时间与空间的权衡

- **早期计算机**：内存资源极其有限，追求**用时间换空间**（如压缩算法、紧凑存储）
- **现代计算机**：内存充足，追求**用空间换时间**（如缓存、哈希表、预处理数组）

### ❓ 为什么需要复杂度分析？

评估算法效率有两种方法，但**事后统计法存在致命缺陷**：

⚠️ **依赖测试环境**：同一段代码在 i9 和 i3 处理器上运行速度差异巨大

⚠️ **依赖数据规模**：小规模数据下，插入排序可能比快速排序更快

因此我们需要**事前分析估算法**：不依赖具体硬件和测试数据，通过数学方法粗略估计算法的执行效率，这就是复杂度分析。

### ⏱️ 时间复杂度基础

#### 1. 📌 核心概念

- **语句频度 $T (n)$**：算法中基本操作（最内层循环体）的执行次数，$n$ 是问题规模
- **渐进时间复杂度 $O (f (n))$**：当 n 趋近于无穷大时，T (n) 与 f (n) 是同数量级函数，记作
$T(n) = O(f(n))$
- **大 O 记号规则**：忽略常数项、低阶项和高阶项的系数，只保留最高阶项

#### 2. 📈 常见复杂度阶数排序
$$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$$
- $O(1)$：常数操作，不随 n 变化
- $O(\log n)$：二分、快速幂
- $O(n)$：单循环、线性遍历
- $O(n \log n)$：高效排序（归并、快排、堆排）
- $O(n^2)$：双重循环、简单排序
- 指数级：暴力枚举，效率极低

💡 各阶数的典型例子：

| 复杂度阶数      | 典型算法 / 操作         |
| :--------- | :---------------- |
| $O(1)$     | 赋值、算术运算、哈希表查找     |
| $O(\log n)$  | 二分查找、快速幂、欧几里得算法   |
| $O(n)$     | 线性遍历、单循环、计数排序     |
| $O(n \log n)$ | 归并排序、快速排序（平均）、堆排序 |
| $O(n^2)$    | 冒泡排序、插入排序、朴素矩阵乘法  |
| $O(n^3)$    | 三重循环、弗洛伊德算法       |
| $O(2^n)$    | 子集生成、斐波那契递归（朴素）   |
| $O(n!)$    | 全排列、旅行商问题（暴力）     |

### 📊 时间复杂度的四种情况

同一段代码在不同输入下，时间复杂度可能有量级差异，因此需要区分以下四种情况：

#### 1. 🌟 最好情况时间复杂度

**最理想输入**下的时间复杂度，发生概率极低，仅作参考。

- 例子：在数组中查找元素，正好第一个元素就是目标，复杂度 $O(1)$

#### 2. 💥 最坏情况时间复杂度

**最糟糕输入**下的时间复杂度，**这是我们通常所说的算法时间复杂度**，保证算法在任何情况下都不会超过这个时间。

- 例子：在数组中查找元素，目标不在数组中，需要遍历整个数组，复杂度 $O(n)$

#### 3. 📊 平均情况时间复杂度

** 所有输入情况的加权平均（期望）** 时间复杂度，更能反映算法的真实性能，但计算复杂。

- 例子：假设元素在数组中每个位置的概率相同，平均需要遍历 $n/2$ 个元素，复杂度 $O(n)$

#### 4. ⚖️ 均摊时间复杂度

一种特殊的平均复杂度，适用于 **"大部分操作 $O (1)$，少数操作 $O (n)$，且有固定时序规律"** 的场景。

- 核心思想：将少数高复杂度操作的耗时，平摊到大量低复杂度操作上
- 例子：动态数组的插入操作，每 n 次插入会触发一次扩容 $O(n)$，其余 n-1 次都是 $O(1)$，均摊下来复杂度为 $O(1)$

> 💡 关键区别：平均复杂度是所有情况的概率平均，均摊复杂度是时序上的平摊，均摊复杂度通常等于最好情况复杂度。

### 💾 空间复杂度（重点补充）

#### 1. 📌 核心定义

空间复杂度 $S (n)$ 是算法运行过程中**临时占用的辅助存储空间**的量级，**不包括输入数据、输出数据和程序本身占用的空间**。

#### 2. 📦 常见空间复杂度阶数

- **$O(1)$：原地算法**
  
    只需要常数个临时变量，空间不随问题规模 n 增长。
    
    - 例子：交换两个变量、冒泡排序、选择排序
    
- **$O(n)$：线性空间**
  
    需要与 n 成正比的辅助空间。
    
    - 例子：数组、链表、哈希表、归并排序的辅助数组
    
- **$O(\log n)$：对数空间**
  
    主要来自**递归调用栈的深度**，是递归算法特有的空间复杂度。
    
    - 例子：二分查找的递归实现、二叉树的前序 / 中序 / 后序遍历（递归）
    
- **$O(n^2)$：平方空间**
  
    需要二维数组、矩阵等存储结构。
    
    - 例子：邻接矩阵存储图、动态规划的二维状态数组
    

#### 3. 🔄 递归算法的空间复杂度

递归算法的空间复杂度**等于递归调用栈的最大深度**，与递归次数无关。

- 例子：阶乘递归的栈深度是 $n$，空间复杂度 $O(n)$
- 例子：二分查找递归的栈深度是 $logn$，空间复杂度 $O(\log n)$

### 🔄 递归算法的时间复杂度计算

递归算法的时间复杂度 = **递归调用的总次数 × 每次递归的基本操作时间**

#### 方法一：📝 递推公式展开法

步骤：

1. 写出递归的递推公式和初始条件
2. 逐层展开递推公式，直到达到初始条件
3. 求和得到总操作次数，化简为大 O 记号

**💡 例子 1：阶乘递归**

```cpp
int factorial(int n) {
    if (n == 1) return 1;
    return n * factorial(n-1);
}
```

- 递推公式：

$$T(n) = T(n-1) + O(1)$$
$$T(1) = O(1)$$
- 展开：
$$T(n) = T(n-1)+1 = T(n-2)+2 = ... = T(1)+(n-1) = n$$

- 时间复杂度：$O(n)$

**💡 例子 2：斐波那契递归（朴素）**

```cpp
int fib(int n) {
    if (n <= 2) return 1;
    return fib(n-1) + fib(n-2);
}
```

- 递推公式与初始条件：
$$T(n) = T(n-1) + T(n-2) + O(1)$$
$$T(1) = O(1)$$
$$T(2) = O(1)$$

- 逐层展开递推式（将 $O(1)$ 替换为常数 $1$）：
> **第 1 层**
$$T(n) = T(n-1) + T(n-2) + 1$$
   > **第 2 层**

$$T(n-1) = T(n-2) + T(n-3) + 1$$
$$T(n-2) = T(n-3) + T(n-4) + 1$$
$$T(n) = T(n-2) + 2T(n-3) + T(n-4) + 3$$

> **第 3 层**

$$T(n-2) = T(n-3) + T(n-4) + 1$$
$$T(n-3) = T(n-4) + T(n-5) + 1$$
$$T(n-4) = T(n-5) + T(n-6) + 1$$
  代入得：
$$T(n) = T(n-3) + 3T(n-4) + 3T(n-5) + T(n-6) + 7$$

- 展开规律：第$k$层共有 $2k−1$ 个 $T$ 项，常数项之和为$2k−1−1$

- 精确求解（特征方程法）：

特征方程：
$$r^2 - r - 1 = 0$$

特征根：

$$r_1 = \frac{1+\sqrt{5}}{2} \approx 1.618$$（黄金分割比$\phi$）
$$r_2 = \frac{1-\sqrt{5}}{2} \approx -0.618$$
    
通解：

$$T(n) = A \cdot \phi^n + B \cdot r_2^n$$

当$n→∞$时，$r_2^n \to 0$，因此：

  $$T(n) \approx A \cdot \phi^n$$

- 复杂度结论：精确复杂度$O(\phi^n) \approx O(1.618^n)$，常用近似$O(2^n)$

### 🎯 主定理（Master Theorem）：分治递归复杂度计算

主定理是快速求解**分治型递归**时间复杂度的工具，适用于以下标准形式的递归：
$$T(n) = a \cdot T\left(\frac{n}{b}\right) + f(n)$$

其中：

- a≥1：子问题的个数
- b>1：每个子问题的规模是原问题的 $\frac{1}{b}$
- f(n)：分解和合并子问题的时间复杂度

#### 主定理的三种情况

比较 $f(n)$ 和 $n^{\log_b a}$ 的增长速度：

1️⃣ **情况 1**：$f(n)=O(n^{\log_b a}−ϵ)$，其中 $ϵ>0$

即 $f(n)$ 比 $n^{\log_b a}$ 增长慢，此时：
$$T(n) = \Theta(n^{\log_b a})$$
**💡 例子：二叉树遍历**
$$T(n) = 2T(n/2) + O(1)$$
$$a=2, b=2, \log_b a=1, f(n)=O(1) = O(n^{1-1})$$
所以 $$T(n) = O(n)$$
2️⃣ **情况 2**：$f(n)=Θ(n^{\log_b a}⋅\log^k n)$，其中 $k≥0$

即 $f(n)$ 和 $n^{\log_b a}$ 同阶，此时：
$$T(n) = \Theta(n^{\log_b a} \cdot \log^{k+1} n)$$
**💡 例子 1：归并排序**
$$T(n) = 2T(n/2) + O(n)$$
$$a=2, b=2, \log_b a=1, f(n)=O(n) = O(n^1 \cdot \log^0 n)$$
所以 $$T(n) = O(n \log n)$$
**💡 例子 2：二分查找**
$$T(n) = T(n/2) + O(1)$$
$$a=1, b=2, \log_b a=0, f(n)=O(1) = O(n^0 \cdot \log^0 n)$$
所以 $$T(n) = O(\log n)$$
3️⃣ **情况 3**：$f(n)=Ω(n^{\log_b a}+ϵ)$，其中 $ϵ>0$，且满足正则条件 $a⋅f(n/b)≤c⋅f(n)（c<1）$

即 $f(n)$ 比 $n^{\log_b a}$ 增长快，此时：
$$T(n) = \Theta(f(n))$$
**💡 例子：大整数平方（朴素分治）**
$$T(n) = T(n/2) + O(n)$$
$$a=1, b=2, \log_b a=0, f(n)=O(n) = \Omega(n^{0+1})$$
所以 $$T(n) = O(n)$$

#### ⚠️ 主定理的适用范围

- ✅ 适用于**子问题规模相同的分治递归**
- ❌ 不适用于指数级递归（如斐波那契）、子问题规模不同的递归

#### 📝 选择题高频秒杀考点

1. 常见算法的时间 / 空间复杂度：重点掌握排序、查找、图算法

#### ⚠️ 常见避坑技巧

1. 大 O 记号忽略常数项：$O(2n)=O(n)$，$O(1000)=O(1)$
2. 递归算法的空间复杂度等于栈深度，不是递归次数
3. 快速排序最坏时间复杂度 $O(n^2)$，平均 $O(n \log n)$
4. 归并排序时间复杂度稳定 $O(n \log n)$，但空间复杂度 $O(n)$

#### 📌 408 高频考点速记

1. **唯一稳定的 $O(n \log n)$ 排序**：归并排序
2. **最坏情况仍为 $O(n \log n)$ 的排序**：堆排序、归并排序、基数排序
3. **空间复杂度 $O(1)$ 的排序**：插入、冒泡、选择、希尔、堆、快速（递归栈）
4. **图算法时间复杂度**：邻接表 $O (n+e)$，邻接矩阵 $O (n^2)$
5. **查找算法平均最快**：哈希查找 $O (1)$
6. **并查集时间复杂度**：$O (α(n))$，近似常数级

5. 🔴 **空间复杂度**：只算辅助空间，递归空间复杂度等于栈深度
