### 📌 核心逻辑：从线性表到顺序表的层级延伸

在明确了**线性表**作为 “一对一” 线性关系的抽象逻辑后，我们需要落地这一逻辑。其中最基础的落地方式，就是**顺序表**，而支撑顺序表运行的底层载体，则是**数组**。

### **Q🔸：顺序表的本质是什么？**

A✅️：顺序表是**以数组为底层载体**，在计算机内存中利用**地址连续**的存储单元，依次存放数据元素的线性表。它是线性表的一种具体实现形态。

---

### 1️⃣ 存储原理 ⭐

顺序表完全依托数组的特性实现存储：

- **内存布局**：先申请一段**连续的内存空间**，将数据元素紧密存入，中间无空隙、无 “脏数据”。
- **逻辑映射**：数据元素的逻辑相邻关系，完全对应物理内存上的地址相邻关系。

### 2️⃣ 核心操作 ⚙️

基于数组的下标访问特性，顺序表支持完整的线性表操作：

- **增 (add)**：插入元素
- **删 (remove)**：移除元素
- **改 (set)**：更新元素
- **查 (find)**：定位元素
- **插 (insert)**：指定位置插入

### 3️⃣ 关键特征 ✨

- **无空位无脏数据**：存储紧凑，有效数据之间没有空闲空间，空间利用率高。
- **强线性约束**：严格满足线性表定义，每个元素（除首尾）必有唯一前驱和后继。
- **完整定义**：顺序表 = 数组（底层存储） + 表长（数据元素个数），两者结合才能唯一确定一个线性表。

---

### 🔗 知识过渡：顺序表与数组的区别

虽然顺序表基于数组实现，但二者并不等同：

- **数组**：是编程语言提供的**基础数据类型**，仅提供连续存储和下标访问，不封装增删改查的业务逻辑。
- **顺序表**：是**数据结构**，是对数组的封装与拓展，包含了 “表长” 概念及完整的线性表操作规范。

### 📝 总结

顺序表是**线性表逻辑**与**数组存储**的结合体。它利用数组 “连续存储、下标随机访问” 的特性，实现了线性表的有序存放；同时通过定义表长与操作接口，解决了纯数组缺乏逻辑边界管理的问题，是理解线性表、链表等复杂结构的基石。
⭐**顺序表是依托基础存储单元数组基于线性表逻辑结构实现的一种存储结构。**

### 💻 具体代码实现如下：

```c
#include<stdlib.h>
#include<stdio.h>
#define maxx 105

// 1.定义一个顺序表类型
// 2.初始化一个顺序表（包括：1.存放数据的连续空间；2.赋初始值。）
// 3.实现增、删、改、查
typedef struct {
	int* data;	// 指向存储数据的连续内存空间
	int s;		// 记录顺序表的实际长度（表长）
}Array;

// 初始化顺序表，返回一个申请完 maxx 大小的空间，标记表长为 0 的空表
Array Init(void)	// 值传递，防止 vs2022 a = Init(a); 报错：a未初始化！陷入 Paradox 悖论
{
	Array t;
	t.data = (int*)malloc(sizeof(int) * maxx);
	/*if (t.data = NULL)
	{
		printf("Application for space failed.\n");
		return;
	}*/
	t.s = 0;	// 空表的表长为 0
	return t;
}

// 在顺序表 a 的表尾添加数据 x
void Add(Array *a, int x)	// Add 函数的目的是修改顺序表本身的状态，用指针传递
{
	a->data[a->s] = x;
	a->s++;
}

// 如果顺序表 a 不满，则将数据 x 嵌入下标为 i 的位置上
// （注意这里与链表不同，链表要用Find，因为链表不知道（或不关注）表长（或位置），关注的是数据k，在数据k后插入）
void Insert(Array* a, int i, int x)
{
	if (a->s == maxx)
	{
		printf("The array is full.\n");
		return;
	}
	else if (i < 0 || i >= a->s)
	{
		printf("This position is out of range and cannot be Inserted\n");
		return;
	}

	//for (int j = a->s - 1; j >= i; i--) // 枚举要移动的数据
	//{
	//	a->data[j + 1] = a->data[j];
	//}
	for (int j = a->s; j > i; j--)	// 枚举移动到的位置
	{
		a->data[j] = a->data[j - 1];
	}

	a->data[i] = x;
	a->s++;
}

// 查找顺序表 a 中的数据 x，如果存在数据 x，返回第一个 x 的下标，否则返回 -1。
int Find(Array* a, int x)
{
	for (int i = 0; i < a->s; i++)
	{
		if (a->data[i] == x)
		{
			return i;
		}
	}
	return -1;
}

// 如果 x 存在，删除顺序表 a 中第一个出现的数据 x
void Delete(Array* a, int x)
{
	int i = Find(a, x);
	if (i == -1)
	{
		printf("This data does not exist and cannot be deleted.\n");
		return;
	}
	for (int j = i; j < a->s; j++)	// 枚举移动到的位置
	{
		a->data[j] = a->data[j + 1];
	}
	a->s--;
}

// 如果顺序表 a 的下标为 i 的位置存在，更改该位置上的数据为新数据 x
void Change(Array* a, int i, int x)
{
	if (i < 0 || i >= a->s)
	{
		printf("This position is out of range and cannot be changed.\n");
		return;
	}
	a->data[i] = x;
}

// 如果顺序表 a 不为空表，输出表中的每一个数据到终端
void Show(Array* a)
{
	if (a->s == 0)
	{
		printf("This table is empty.\n");
		return;
	}
	for (int i = 0; i < a->s; i++)
	{
		printf("%d ", a->data[i]);
	}
	printf("\n");
}

int main()
{
	Array a = Init();
	Show(&a);
	Add(&a, 3), Add(&a, 1), Add(&a, 2), Add(&a, 5), Add(&a, 6), Add(&a, 7);
	Show(&a);
	Insert(&a, 3, 9);
	Insert(&a, 3, 10);
	Insert(&a, 20, 5);
	Show(&a);
	Change(&a, 2, 8);
	Change(&a, 7, 11);
	Change(&a, 20, 5);
	Show(&a);
	Delete(&a, 13);
	Delete(&a, 9);
	Delete(&a, 3);
	Show(&a);

	return 0;
}
```
### 📦 顺序表的优缺点与适用场景

**Q🔸：顺序表有哪些优缺点？**

A✅️：

- **优点**：实现简单，支持**随机存取**（通过 “首地址 + 偏移量” 直接计算访问地址）。
    
    - ⚠️ 补充：这个 “随机存取” 的优点在实际开发中**并不常用**。因为要进行随机存取，就必须预先知道元素的下标位置，而如果已经知道了位置，也就不需要再进行查找操作了。
    
- **缺点**：插入和删除操作比较繁琐，需要移动大量元素，时间复杂度为 O (n)。
    
- **适用场景**：适合存储**静态数据**，即数据元素不频繁增删，更多用于查询和遍历的场景。
