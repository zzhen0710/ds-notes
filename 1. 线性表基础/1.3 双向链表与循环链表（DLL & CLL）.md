# 双向链表：线性表的双向链式实现 🔸

### 📌 核心逻辑：从单链表到双向链表的升级

单链表只能**向后遍历**，找前驱结点必须从头重新遍历；

双向链表在单链表基础上，给每个结点增加**前驱指针`pre`**，实现**向前 + 向后双向遍历**，是对单链表的功能升级。

### **Q🔸：双向链表的本质是什么？**

A✅️：

双向链表是**每个结点包含三个部分**的链式线性表：

1. **数据域`data`**：存储数据
2. **前驱指针`pre`**：指向**上一个结点**
3. **后继指针`next`**：指向**下一个结点**

它支持**双向遍历**，插入 / 删除操作更方便，但多占用一个指针的空间。

---

### 🔑 核心知识点 📝

#### 1. 结构特点

- 头结点的`pre`固定为`NULL`
- 尾结点的`next`固定为`NULL`
- 任意中间结点：`p->pre->next = p` 且 `p->next->pre = p`

#### 2. 与单链表最大区别

- 单链表：只能向后走，**无法直接找前驱**
- 双向链表：**可向前可向后**，找前驱 / 后继都极快
- 空间代价：每个结点多一个`pre`指针

#### 3. 操作核心原则 ✨

在对双向链表进行插入、删除时，**重点关注两个指针域**：

1. **前驱结点`pre`的`next`**
2. **新结点 / 待删结点自身的`pre/next`**
    
    合理操作这两个指针，就能稳定完成所有链表操作。

---

### ⚠️ 双向链表必记细节（考试 / 代码常错）

**Q🔸：双向链表最容易出错的地方？**

A✅️：

1. **指针赋值顺序不能乱**
    
    插入时必须**先判断后结点是否存在**，再修改指针，颠倒会导致判断失效。
    
2. **`free`后绝对不能访问结点**
    
    `free(p)`会把**整个结点一起释放**，释放后不能再使用`p->pre`/`p->next`，否则是野指针非法访问。
    
3. **删除结点必须同时修改两条链**
    
    既要改前驱的`next`，也要改后继的`pre`，缺一不可。

### 💻 单链表核心操作代码实现（C 语言）

```c
#include<stdio.h>
#include<stdlib.h>

namespace Doubly_Linked_List {
	// 双向链表结点结构：数据域 + 后继指针 + 前驱指针
	typedef struct Node {
		int data;        // 数据域：存储有效数据
		struct Node* next;      // 后继指针：指向后一个结点
		struct Node* pre;       // 前驱指针：指向前一个结点
	}Node, * LinkList;

	// 初始化双向链表：创建带头结点的空链表
	LinkList initLink(void)
	{
		Node* head = (Node*)malloc(sizeof(Node));
		head->next = NULL;   // 初始无后继结点
		head->pre = NULL;    // 头结点前驱固定为空

		return head;
	}

	// 头插法：在头结点后插入新结点x
	void headInsert(LinkList& L, int x)
	{
		Node* s = (Node*)malloc(sizeof(Node));
		s->data = x;
		s->next = L->next;   // 新结点后继指向原首元结点
		s->pre = L;          // 新结点前驱指向头结点

		// ⚠️ 必须先判断原首元结点是否存在，顺序不可颠倒
		if (L->next != NULL)
			L->next->pre = s;
		L->next = s;         // 头结点后继指向新结点，完成插入
	}

	// 尾插法：在链表尾部插入新结点x
	void rearInsert(LinkList& L, int x)
	{
		Node* p = L;
		// 遍历找到链表尾结点
		while (p->next != NULL)
		{
			p = p->next;
		}

		Node* s = (Node*)malloc(sizeof(Node));
		s->data = x;
		s->next = NULL;      // 尾结点后继为空
		s->pre = p;         // 新结点前驱指向原尾结点

		p->next = s;        // 原尾结点后继指向新结点
	}

	// 查找函数：查找值为k的结点，找到返回结点地址，否则返回NULL
	Node* Find(const LinkList& L, int k)
	{
		Node* p = L->next;   // 从首元结点开始遍历
		// 未到表尾且未找到目标结点，继续向后遍历
		while (p != NULL && p->data != k)
		{
			p = p->next;
		}
		return p;
	}

	// 指定位置插入：在值为k的结点后插入值为x的新结点
	void Insert(LinkList& L, int k, int x)
	{
		Node* p = Find(L, k);
		if (p == NULL)
		{
			printf("The insertion failed : The data %d does not exist in the List.\n", k);
			return;
		}
		Node* s = (Node*)malloc(sizeof(Node));
		s->data = x;
		s->next = p->next;   // 新结点后继指向p的后继结点
		s->pre = p;          // 新结点前驱指向p

		// ⚠️ 先处理后继结点的前驱指针
		if (p->next != NULL)
			p->next->pre = s;
		p->next = s;         // p的后继指向新结点
	}

	// 删除函数：删除值为k的结点
	void Delete(LinkList& L, int k)
	{
		Node* p = Find(L, k);
		if (p == NULL)
		{
			printf("The deletion failed : The data %d does not exist in the List.\n", k);
			return;
		}
		// 前驱结点的后继直接指向p的后继结点，摘除p
		p->pre->next = p->next;
		// 若p有后继结点，修改后继结点的前驱指针
		if (p->next != NULL)
			p->next->pre = p->pre;

		// ⚠️ 释放结点后，不可再访问p的pre/next
		free(p);
		p = NULL;
	}

	// 修改函数：将值为k的结点数据修改为x
	void Change(LinkList& L, int k, int x)
	{
		Node* p = Find(L, k);
		if (p == NULL)
		{
			printf("The change failed : The data %d does not exist in the List.\n", k);
			return;
		}
		p->data = x;   // 直接修改数据域
	}

	// 清空链表：释放所有数据结点，保留头结点
	void deleteLink(LinkList& L)
	{
		while (L->next != NULL)
		{
			Node* p = L->next;
			L->next = p->next;   // 头结点后移

			// ⚠️ 直接释放结点，不操作已释放空间
			free(p);
			p = NULL;
		}
	}

	// 遍历输出链表所有数据
	void Show(LinkList& L)
	{
		Node* p = L->next;
		if (p == NULL)
		{
			printf("The show failed : The List is empty.\n");
			return;
		}
		// 从首元结点遍历至表尾
		while (p != NULL)
		{
			printf("%d ", p->data);
			p = p->next;
		}
		printf("\n");
	}

	// 双向链表功能测试
	void runTest(void)
	{
		LinkList L = initLink();
		Show(L);

		Insert(L, 100, 1);
		Delete(L, 100);
		Change(L, 100, 1);
		Show(L);
		
		//（...内容重复略）
	}
}

void main()
{
	Doubly_Linked_List::runTest();
}
```
### 📊 双向链表优缺点

**Q🔸：双向链表有哪些优缺点？**

A✅️：

#### 优点 ✨

- 支持**双向遍历**，找前驱 / 后继极快
- 插入、删除操作比单链表更方便
- 功能更强大，适用范围更广

#### 缺点 ⚠️

- 每个结点多一个`pre`指针，**空间开销更大**
- 插入 / 删除需要修改更多指针，逻辑稍复杂

#### 适用场景 🎯

需要**频繁双向遍历、快速找前驱结点**的场景。

---

### 📝 总结

1. 双向链表 = 数据域 + 前驱指针`pre` + 后继指针`next`，实现**双向遍历**
2. 操作核心：管好**前驱结点的`next`** 和 **自身的`pre/next`**
3. 重点：指针赋值有顺序、`free`后不访问结点成员
4. 是单链表的功能升级版，用少量空间换取更强遍历能力

# 循环链表：线性表的循环链式实现 🔸

### 📌 核心逻辑：从单链表 → 循环链表

**循环链表 = 带头结点的单链表 + 尾结点指向头结点**

最大特点：**没有 NULL 指针**，尾结点的 `next` 不再为空，而是**指回头结点**，形成一个闭环。

### **Q🔸：循环链表的核心改动是什么？**

A✅️：

**只在单链表基础上修改一处规则：**

- 单链表：尾结点 `next = NULL`
- 循环链表：尾结点 `next = 头结点 L`

所以**绝大多数函数和单链表完全一样**，

**只需要修改涉及「判空 / 找尾 / 遍历终止」的函数。**

---

### 🔑 循环链表核心知识点 📝

**Q🔸：循环链表与单链表的区别？**

A✅️：

1. **遍历结束条件不同**
    
    - 单链表：`p == NULL`
    - 循环链表：`p == L`（回到头结点就停止）
    
2. **判空条件不同**
    
    - 单链表：`L->next == NULL`
    - 循环链表：`L->next == L`
    
3. **找尾结点更方便**
    
    不用遍历到 NULL，而是遍历到 `p->next == L` 就是尾结点。

---

# 💻 循环链表：仅【改动过的函数】（对比单链表）

以下是**在单链表基础上必须修改**的函数，

**其余函数（Insert / Change / Find 等）和单链表完全一致，无需改动！**

```c
namespace Circular_Linked_List {
	typedef struct Node {
		int data;
		Node* next;
	}Node, * LinkList;

	// ==============================
	// 改动 1：初始化
	// 单链表：head->next = NULL
	// 循环链表：head->next = head 闭环
	// ==============================
	Node* initLink(void)
	{
		Node* head = (Node*)malloc(sizeof(Node));
		head->next = head;  // 空表：自己指向自己
		return head;
	}

	// ==============================
	// 改动 2：尾插法（最典型修改）
	// 单链表：p->next == NULL
	// 循环链表：p->next == L 就是尾结点
	// ==============================
	LinkList rearInsert(LinkList L, int x)
	{
		Node* s = (Node*)malloc(sizeof(Node));
		s->data = x;
		s->next = L;       // 新结点指向头结点

		// 找尾：p->next == L 就是尾结点
		Node* p = L;
		while (p->next != L)
		{
			p = p->next;
		}
		p->next = s;
		return L;
	}

	// ==============================
	// 改动 3：查找（遍历结束条件）
	// 单链表：p == NULL
	// 循环链表：p == L 就停止
	// ==============================
	Node* Find(LinkList L, int x)
	{
		Node* p = L->next;
		// 回到头结点就停止，不无限循环
		while (p != L && p->data != x)
		{
			p = p->next;
		}
		return p;
	}

	// ==============================
	// 改动 4：删除（遍历结束条件）
	// ==============================
	LinkList Delete(LinkList L, int k)
	{
		Node* pre = L, * p = L->next;
		// 回到头结点停止
		while (p != L && p->data != k)
		{
			pre = pre->next;
			p = p->next;
		}
		if (p == L)
		{
			printf("This data does not exist and cannot be deleted.\n");
		}
		else
		{
			pre->next = p->next;
			free(p);
			p = NULL;
		}
		return L;
	}

	// ==============================
	// 改动 5：清空链表（判空条件）
	// ==============================
	LinkList deleteLink(LinkList L)
	{
		// 空表：L->next == L
		while (L->next != L)
		{
			Node* p = L->next;
			L->next = p->next;
			free(p);
			p = NULL;
		}
		return L;
	}

	// ==============================
	// 改动 6：遍历打印（结束条件）
	// ==============================
	void Show(LinkList L)
	{
		Node* p = L->next;
		if (p == L)   // 空表判断
		{
			printf("The Linked List is empty.\n");
		}
		else while (p != L)  // 回到头结点停止
		{
			printf("%d ", p->data);
			p = p->next;
		}
		printf("\n");
	}
}
```


### 🔑 单链表→循环单链表 核心改动总结

**本质：所有涉及尾结点判 NULL 的函数，只需把终止条件从「NULL」改为「表头 L」**

#### ✅ 补充说明

- 循环单链表核心特征：尾结点`next`指针不再指向`NULL`，而是回指表头结点`L`，形成逻辑闭环
- 改动范围：仅需修改遍历、判尾、查找等所有「判断链表末尾」的逻辑
- 其余增删改操作：和普通单链表完全一致，无需额外调整

# 🔍 循环双向链表：为什么可以**删掉判空**？

我给你写**两个典型函数 + 核心解释**，完全贴合你的笔记风格👇

### **Q🔸：循环双链表为什么不用判空（`if (p->next != NULL)`）？**

A✅️：

**因为循环双链表不存在 NULL！**

- 尾结点的 `next` → 头结点
- 头结点的 `pre` → 尾结点
- 全表闭环，**永远不会出现 NULL**

所以原来双链表中：

```c
if (p->next != NULL)
    p->next->pre = ...
```

**在循环双链表中可以直接删掉！**

---

# 💻 循环双向链表：额外改动示例（删去判空 / 特判）

```c
// 循环双向链表 - 头插（不用判空！）
void headInsert(DLinkList& L, int x)
{
    Node* s = makeNode(x);

    // ==============================
    // ⭐ 改动重点：
    // 普通双链表：要 if (L->next != NULL)
    // 循环双链表：无 NULL，直接写！
    // ==============================
    s->next = L->next;
    L->next->pre = s;   // 直接用，不用判断

    s->pre = L;
    L->next = s;
}

// 循环双向链表 - 指定插入（不用判空！）
void Insert(DLinkList& L, int k, int x)
{
    Node* p = Find(L, k);
    Node* s = makeNode(x);

    s->next = p->next;
    p->next->pre = s;   // 直接用，无 NULL

    s->pre = p;
    p->next = s;
}
```

### **Q🔸：循环双链表为什么敢删掉判空？**

A✅️：

因为**闭环保证了每个结点都有后继**，

哪怕是尾结点，它的 `next` 也是头结点，**绝对不会出现 NULL**。

所以**所有判断 `xxx != NULL` 的代码都可以删除**，代码更简洁！

---

### ⚠️ 循环双向链表尾插法专属必记细节

**Q🔸：尾插法为什么必须给头结点的 pre 赋值？**

A✅️：

循环双向链表的核心是**双向全闭环**，必须同时维护两条完整的链：

1. 正向链：头结点 → 首元结点 → ... → 尾结点 → 头结点
2. 反向链：头结点 → 尾结点 → ... → 首元结点 → 头结点

如果尾插时只修改了尾结点的 next，漏掉 `L->pre = 新结点`，反向链就会直接断裂，头结点找不到新的尾结点，闭环失效，后续的遍历、插入、删除都会出现逻辑错误。

同时这个特性也带来了巨大优势：循环双向链表**无需遍历找尾**，直接通过 `L->pre` 就能 O (1) 拿到尾结点，尾插效率比普通双链表的 O (n) 提升了一个量级。

---

## 📊 循环链表总结（极简好记版）

**Q🔸：循环链表怎么记？**

A✅️：

1. **单链表改一改 = 循环链表**
2. **NULL 全换成 头结点 L**
3. 判空：`L->next == L`
4. 找尾：`p->next == L`（循环双向链表直接 `L->pre` 拿尾结点）
5. 遍历结束：`p == L`
6. **双向循环链表额外特性 1：无 NULL → 所有判空语句可删除**
7. **双向循环链表额外特性 2（易忘）：尾插法必须维护 L->pre 指向新尾结点，保证双向闭环**

# 📊 循环链表 & 双向循环链表 优缺点

#### 单向循环链表

- **优点**：从任意结点可遍历全表；无 `NULL` 解引用风险；学习成本低
- **缺点**：遍历易死循环；找前驱仍需 O (n) 遍历

#### 双向循环链表（额外优点）

- **优点**：彻底无 `NULL`，可删除所有判空代码；双向 + 循环遍历，插入 / 删除逻辑更简洁；O (1) 时间直接获取尾结点，尾插效率拉满
- **缺点**：空间开销更大；必须严格维护双向闭环，否则易出现遍历异常；仍需注意遍历终止条件，避免死循环

---

### 🎯 适用场景

- 单向循环：轮询调度、循环队列
- 双向循环：操作系统进程链表、环形缓冲区、LRU 缓存等高频头尾操作、双向遍历场景
