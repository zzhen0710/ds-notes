## 🏷️ 查找基础前置概念📚

### 1. 查找定义

在一组数据元素中检索目标关键字，存在则**查找成功**，不存在则**查找失败**。

- 数据元素：由多个字段组成，唯一标识元素的字段称为**关键字 / 主键**；示例 `{ID,姓名,年龄}`，ID 为主关键字。
- 简化约定：本章所有算法默认数据元素仅包含单一关键字。

### 2. 查找分类

1. **静态查找**：数据集极少增删，仅查询；包含顺序查找、折半查找、分块查找、哈希查找。
2. **动态查找**：数据集频繁插入 / 删除；二叉搜索树、平衡树、哈希查找。
3. **内查找**：全部数据载入内存；本章三种均为内查找。
4. **外查找**：数据存磁盘，仅部分载入内存（数据库、文件索引）。

### 3. 平均查找长度 ASL（核心衡量指标）

查找长度：单次查找过程中关键字比较次数。

**$ASL（平均查找长度）$**：等概率下，多次查找的平均比较次数。

设共 $n$ 个数据，每个元素查找概率 $P_i=\frac{1}{n}$​，第 $i$ 个元素查找长度为 $C_i$​：

$$\text{ASL}_{成功} = P_1C_1 + P_2C_2 + \dots + P_nC_n$$

$$\text{ASL}_{失败}$$

## 一、顺序查找（线性查找）🔍

### 1. 核心原理

时间复杂度 $O(n)$，支持**顺序存储、链式存储**，无需数组有序。

流程：从表头到表尾依次将每个元素与目标 k 比对；匹配则查找成功；全部遍历无匹配则查找失败。

### 2. ASL 公式（等概率）

$$\text{ASL}_{成功} = \frac{1+2+3+\dots+n}{n} = \frac{n+1}{2}$$
$$\text{ASL}_{失败} = n+1$$

### 3. C++ 完整源码（注释增补知识点）

```cpp
// ---------- 1. 顺序查找 ----------
/// 线性遍历查找，无序/有序线性表均可使用，链表唯一可用查找算法
int SequentialSearch::Search(int target) const {
    int n = static_cast<int>(data_.size());
    // 从头到尾线性遍历，逐个比对目标值
    for (int i = 0; i < n; ++i) {
        if (data_[i] == target) {
            return i; // 匹配成功，返回元素下标
        }
    }
    return -1; // 遍历结束未找到，返回 -1 标记失败
}
```

### 4. 优缺点总结

✅ 优点：不要求数据有序、兼容数组与链表、实现极简；

❌ 缺点：平均查找长度大，大数据量效率极低。

## 二、折半查找（二分查找）⚖️

### 1. 前置硬性前提

**线性表必须有序（升序）**，且仅支持**顺序存储**（链表无法随机访问下标，不能二分）。

### 2. 完整查找流程

设待查目标 $k$，闭区间查找范围 $[l,r]$

1. 计算中点：$mid = l + \frac{r-l}{2}$，规避 $l+r$ 数值溢出；
2. 分支判断：
    
    1. $k==a[mid]$：查找成功，返回 $mid$；
    2. $k>a[mid]$：目标在右半区间，更新 $l=mid+1$；
    3. $k<a[mid]$：目标在左半区间，更新 $r=mid−1$；
    
3. 循环终止条件：$l>r$，区间收缩完毕，查找失败。

>### 补充：折半查找对应严格平衡二叉判定树🌳

1. 判定树构造规则
    
    将有序数组中间元素作为根节点；左半区间元素递归构造左子树，右半区间元素递归构造右子树；最终生成**严格平衡二叉树**，左右子树高度差不超过 $1$。
1. 判定树与查找长度的对应关系

- 查找成功：路径经过的节点数量 = 关键字比较次数（查找长度）；根节点比较 $1$ 次，第二层 $2$ 次…… 第 $h$ 层最多比较 $h$ 次；
- 查找失败：落在判定树外部叶子（虚节点），对应区间不存在目标值的场景；

3. 树高度与复杂度关联
    
    $n$ 个节点的平衡二分判定树高度 $h=⌊log2​n⌋+1$，直接决定最坏查找比较次数。

### 3. 性能说明

每次区间规模折半，时间复杂度 $O(\log n)$；

可分别计算 成功、失败。

### 4. C++ 完整源码

```cpp
// ---------- 2. 折半查找 ----------
/// 二分查找，仅适用于有序顺序表，随机访问下标是核心基础
int BinarySearch::Search(int target) const {
    int left = 0;
    int right = static_cast<int>(data_.size()) - 1;

    // 闭区间 [left, right] 二分查找循环
    while (left <= right) {
        // 中点防溢出写法，避免 left+right 超出 int 数值范围
        int mid = left + (right - left) / 2;

        if (data_[mid] == target) {
            return mid; // 找到目标，返回下标
        }
        else if (data_[mid] < target) {
            left = mid + 1; // 目标值更大，收缩至右半区查找
        }
        else {
            right = mid - 1; // 目标值更小，收缩至左半区查找
        }
    }
    return -1; // 区间收缩完毕未找到，查找失败
}
```

### 5. 优缺点

✅ 优点：平均查找长度极小，大数据量查询速度极快；

❌ 缺点：必须有序顺序存储，增删元素需要移动大量数据，不适合频繁修改的表。

## 三、分块查找（索引顺序查找）🗂️

### 1. 底层基础：索引存储概念

索引存储：给原始数据表额外建立一张**索引表**；

将原始数据分多块，每块提取一个关键字（通常取块最大值），索引项格式 关键字块起始地址。

>#### 📍分块索引查找示意图：

![基本查找 1.png](<../pict/基本查找 1.png>)

### 2. 核心规则

1. 分块要求：**块间有序、块内无序**；前一块所有元素最大值 ≤ 后一块所有元素最大值；
2. 两步查找流程：
    
    ① 在有序索引表上执行**折半查找**，快速定位目标所属数据块；
    
    ② 在对应数据块内部执行**顺序查找**，遍历块内元素匹配目标。

### 3. 时间复杂度拆分

- 索引表二分：$O(\log m)$，$m$ 为总块数；
- 块内顺序查找：$O(\frac{n}{m})$，每块平均 $\frac{n}{m}$个元素；
    
    整体复杂度介于顺序查找与二分查找之间。

### 4. C++ 完整源码（自带动态构建索引表逻辑）

```cpp
// ---------- 3. 分块查找 ----------
/// 设置每块容纳元素数量，非法输入自动兜底为5
void BlockSearch::SetBlockSize(int size) noexcept {
    block_size_ = size > 0 ? size : 5;
}

/// 分块查找主逻辑：二分索引表定位块 + 块内顺序查找
int BlockSearch::Search(int target) const {
    int n = static_cast<int>(data_.size());
    if (n == 0) return -1;

    // ① 计算块的总数量，向上取整保证全部元素都能分到块内
    int block_count = (n + block_size_ - 1) / block_size_;
    std::vector<int> index_table(block_count);

    // ② 构建索引表：记录每个块内的最大值，满足块间有序条件
    for (int i = 0; i < block_count; ++i) {
        int start = i * block_size_;
        int end = std::min(start + block_size_, n);
        int max_val = data_[start];
        for (int j = start + 1; j < end; ++j) {
            if (data_[j] > max_val) {
                max_val = data_[j];
            }
        }
        index_table[i] = max_val;
    }

    // ③ 二分查找有序索引表，确定目标值所在的块下标
    int left = 0, right = block_count - 1;
    int block_idx = block_count;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (index_table[mid] >= target) {
            block_idx = mid;
            right = mid - 1;
        }
        else {
            left = mid + 1;
        }
    }

    // 所有块的最大值都小于目标值，直接判定未找到
    if (block_idx >= block_count) {
        return -1;
    }

    // ④ 在目标块内执行顺序查找，逐个比对元素
    int start = block_idx * block_size_;
    int end = std::min(start + block_size_, n);
    for (int i = start; i < end; ++i) {
        if (data_[i] == target) {
            return i;
        }
    }

    return -1; // 块内遍历完毕未匹配，查找失败
}
```

### 5. 优缺点

✅ 优点：兼顾查询效率与增删效率；仅需修改单块内数据，无需整体移动；

❌ 缺点：需要额外内存存储索引表，块内无序无法进一步优化。

## 一句话核心逻辑总结✨

1. **顺序查找**：从头到尾逐个比对元素，不限制数据顺序与存储结构，实现最简单但最慢。
2. **折半查找**：依托有序数组随机访问，每次砍掉一半查找区间，查询速度最优，但增删开销大。
3. **分块查找**：分块建立最大值索引，先二分索引定位块，再块内线性查找，平衡查询与修改性能。
