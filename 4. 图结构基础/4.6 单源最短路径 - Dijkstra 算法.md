## 一、📖 最短路径基础概念

### 1.1 路径长度定义

- **无权图**：两点之间路径上的边的数量，即为路径长度
- **带权图**：两点之间路径上所有边的权值之和，即为路径长度

### 1.2 最短路径定义

两个顶点之间可能存在多条不同路径，其中路径长度（边数 / 权值和）最小的那条，称为两点之间的**最短路径**，对应的长度称为最短距离。

### 1.3 无向图与有向图的差异

- **无向图**：A→B 和 B→A 的路径完全一致，最短距离相同
- **有向图**：A→B 和 B→A 的路径不一定相同，最短距离可能完全不同

## 二、🎯 单源最短路径问题定义

### 2.1 问题描述

给定一个带权图和一个固定的起点（源点 s），求解从源点 s 出发，到图中其他所有顶点的最短路径长度，同时可以回溯得到具体路径。

### 2.2 Dijkstra 算法适用边界

✅ 适用：**所有边权值非负**的带权图（无向图、有向图均可）

❌ 不适用：存在负权边的图（贪心策略会失效，得到错误结果）

---

## 三、🧠 Dijkstra 算法核心思想

### 3.1 核心贪心策略

Dijkstra 是典型的**贪心算法**，核心逻辑基于两个关键性质：

1. **最短路径的前缀最优性**：从起点 s 到任意顶点 v 的最短路径，它的所有前缀子路径，一定也是 s 到对应中转点的最短路径。
    
    > 通俗理解：如果 `s→...→u→v` 是 s 到 v 的最短路径，那么 `s→...→u` 一定是 s 到 u 的最短路径。
    
2. **最近顶点确定性**：所有未确定最短路径的顶点中，当前 dist 值最小的那个顶点，它的最短路径已经可以确定，不会再被更新。
    
    > 通俗理解：离起点最近的那个点，不可能通过绕其他点得到更短的路径（因为所有边权都是非负的，绕路只会更远）。
    

### 3.2 核心操作：松弛（Relaxation）

松弛操作是 Dijkstra 的基础单元：对于边 `u→v`（权值 w），判断「经过 u 中转到 v」是否比「当前已知的到 v 的最短路径」更短。

- 公式：`if (dist[u] + w < dist[v]) dist[v] = dist[u] + w`
- 作用：每确定一个顶点 u 的最短路径，就用 u 作为中转点，尝试更新它所有邻接点的最短路径估计值。

## 四、✅ Dijkstra 算法正确性证明

我们通过 **贪心选择性质 + 最优子结构性质** 结合反证法证明：每次选出的 dist 最小的未访问顶点，其 dist 值就是源点到它的最短路径长度。

### 4.1 前提条件

图中所有边的权值均为非负数。

### 4.2 证明过程

设当前选出的顶点为 u，它是所有未访问顶点中 dist 值最小的。我们假设「dist [u] 不是 s 到 u 的最短路径长度」，推出矛盾。

1. 如果存在另一条更短的路径 `s→...→v→u`，其中 v 是未访问的顶点。
2. 因为所有边权非负，所以 `s到v的最短路径长度 < s到v的最短路径长度 + v到u的边权 < dist[u]`。
3. 这意味着 `dist[v] < dist[u]`，和「u 是未访问顶点中 dist 最小的」前提矛盾。

因此假设不成立，dist [u] 就是 s 到 u 的最短路径长度，贪心选择正确。

### 4.3 最优子结构验证

当 u 的最短路径确定后，用 u 松弛其邻接点 v，得到的 dist [v] 依然是 v 的最短路径估计值。因为 s 到 v 的最短路径要么不经过 u，要么经过 u（此时`s→u→v`的路径长度就是`dist[u]+w`），松弛操作刚好覆盖了这种情况。

> ⚠️ 关键：**负权边会破坏这个证明**。如果存在负权边，绕路可能得到更短的路径，贪心选最小 dist 就不再正确，这也是 Dijkstra 不能处理负权图的根本原因。

## 五、📝 Dijkstra 算法完整执行步骤

### 步骤 1：初始化

1. 初始化 dist 数组：源点`dist[s] = 0`，其余所有顶点`dist = INF`
2. 初始化 visited 数组：所有顶点标记为未访问（false）
3. 初始化 prev 数组：所有顶点前驱置为 - 1

### 步骤 2：循环迭代（共 n 次，确定 n 个顶点的最短路径）

每一轮循环执行以下操作：

1. **贪心选点**：遍历所有顶点，选出未访问且 dist 值最小的顶点 u
2. **标记确定**：将 u 标记为已访问（`visited[u] = true`），u 的最短路径正式确定
3. **松弛更新**：遍历 u 的所有邻接点 v，如果 v 未被访问，且 `dist[u] + 边权(u,v) < dist[v]`，则更新`dist[v]`，并设置`prev[v] = u`

### 步骤 3：终止条件

- 所有顶点都被标记为已访问，算法结束
- 若中途找不到可选顶点（剩余顶点 dist 均为 INF），说明剩余顶点不可达，算法提前结束

## 六、⚡ 存图方式与时间复杂度分析

Dijkstra 的时间开销主要来自两部分：**选点的开销** + **松弛更新的开销**，不同的存图方式和优化手段会带来巨大的复杂度差异。

### 6.1 朴素版：邻接矩阵存储

#### 实现逻辑

- 选点：每次遍历全部 n 个顶点找最小值，单次 $O (n)$，共 n 轮 → $O(n^2)$
- 松弛：每个顶点遍历整行 n 个元素找邻接点，单次 $O (n)$，共 n 轮 → $O(n^2)$

#### 总时间复杂度

**$O(n^2)$**，和边数完全无关。

#### 空间复杂度

邻接矩阵本身$O(n^2)$，辅助数组$O(n)$，总 **$O(n^2)$**。

#### 适用场景

**稠密图**（边数接近$n^2$），此时邻接矩阵访问效率高，代码实现简单。

### 6.2 朴素版：邻接表存储

#### 实现逻辑

- 选点：依然需要遍历全部 n 个顶点找最小值，总开销 $O(n^2)$
- 松弛：每个顶点只遍历自己的邻接点，所有顶点加起来总共遍历 $2e$ 条边（无向图），总开销 $O(e)$

#### 总时间复杂度

**$O(n^2+e)$=$O(n^2)$**，主导项还是选点的$n^2$，和邻接矩阵版同阶。

#### 空间复杂度

邻接表本身$O(n+e)$，辅助数组$O(n)$，总 **$O(n+e)$**。

#### 特点

稀疏图下比邻接矩阵省空间，但时间复杂度没有本质提升，因为选点的瓶颈还在。

### 6.3 优化版：邻接表 + 小顶堆（优先队列）

#### 实现逻辑

用小顶堆（优先队列）替代暴力遍历选点，把「找最小 dist 顶点」的操作从 $O (n)$ 降到 $O (logn)$。

- 选点：每次从堆顶取最小元素，单次 $O(logn)$，最多 e 次入堆 → $O(elogn)$
- 松弛：遍历邻接表，更新后将新的 dist 入堆，总开销$O(elogn)$

#### 总时间复杂度

**$O(elogn)$**，和边数线性相关。

#### 适用场景

**稀疏图**（边数远小于$n^2$），此时堆优化收益极大，性能远优于朴素版。

```cpp
namespace shortest_path {

    class Dijkstra {
    public:
        /// 🏗️ 默认构造函数
        Dijkstra() noexcept;
        /// 🗑️ 析构函数

        /// @return 源点到终点的最短距离

        /// @param graph 邻接矩阵图对象
        /// @param start_vertex 源点编号（与图的顶点编号一致）
        void ComputeSP(const AM& graph, int start_vertex);

        /// @brief 打印所有顶点的最短路径结果
        /// @param graph 邻接矩阵图对象
        void PrintSP(const AM& graph) const;

    private:
        /// 🔙 回溯前驱数组，生成指定终点的完整路径
        std::vector<AM::Edge> GetPathHelper(const AM& graph, int end_idx) const;
        /// ⚡ Dijkstra核心算法实现（选点+松弛）
        void ComputeHelper(const AM& graph, int start_idx);
        /// 🖨️ 打印结果辅助函数
        void PrintHelper(const AM& graph) const;

        // ========== 算法结果与状态变量 ==========
        std::vector<int> dist_;       ///< 📏 源点到各顶点的最短距离数组
        std::vector<int> prev_;       ///< 🧭 各顶点最短路径的前驱顶点下标
        int start_vid_;                ///< 📍 源点在邻接矩阵中的下标
        bool is_computed_;             ///< ✅ 算法计算状态标记，防止未计算就查询结果

    };
```

### ⚙️ 模块 2：实现文件 dijkstra.cpp

> 实现所有成员函数，包含核心算法逻辑、路径回溯、结果打印等功能

```cpp
#include "dijkstra.h"
#include <iostream>
#include <stdexcept>
#include <algorithm>
#include <format>

namespace shortest_path {
    // ====================== 构造与析构 ======================
    Dijkstra::Dijkstra() noexcept
        : dist_()
        , prev_()
        , start_vid_(-1)
        , is_computed_(false) {
    }

    Dijkstra::~Dijkstra() noexcept {
        dist_.clear();
        prev_.clear();
    }

    // ====================== 公有查询接口 ======================
    int Dijkstra::GetDistance(const AM& graph, int end_vertex) const {
        if (!is_computed_) {
            throw std::runtime_error("GetDistance failed: shortest path has not been computed yet.");
        }

        int end_idx = graph.Find(end_vertex);
        if (end_idx == -1) {
            throw std::runtime_error("GetDistance failed: end vertex does not exist in graph.");
        }
        return dist_[end_idx];
    }

    std::vector<AM::Edge> Dijkstra::GetPath(const AM& graph, int end_vertex) const {
        if (!is_computed_) {
            throw std::runtime_error("GetPath failed: shortest path has not been computed yet.");
        }

        int end_idx = graph.Find(end_vertex);
        if (end_idx == -1) {
            throw std::runtime_error("GetPath failed: end vertex does not exist in graph.");
        }
        return GetPathHelper(graph, end_idx);
    }

    // ====================== 算法入口函数 ======================
    void Dijkstra::ComputeSP(const AM& graph, int start_vertex) {
        // 🔄 重置所有状态，支持多次重复调用计算不同源点
        dist_.clear();
        prev_.clear();
        is_computed_ = false;
        start_vid_ = -1;

        int vertex_cnt = graph.GetVertexCount();
        if (vertex_cnt <= 0) {
            throw std::invalid_argument("ComputeSP failed: graph has no valid vertices.");
        }

        // 校验源点合法性，转换为邻接矩阵内部下标
        int start_idx = graph.Find(start_vertex);
        if (start_idx == -1) {
            throw std::runtime_error("ComputeSP failed: start vertex does not exist in graph.");
        }
        start_vid_ = start_idx;

        // 📏 初始化距离数组与前驱数组
        dist_.resize(vertex_cnt, INF);
        prev_.resize(vertex_cnt, -1);
        dist_[start_idx] = 0;

        // 🚀 执行Dijkstra核心算法
        ComputeHelper(graph, start_idx);

        is_computed_ = true;
    }

    void Dijkstra::PrintSP(const AM& graph) const {
        if (!is_computed_) {
            throw std::runtime_error("PrintSP failed: shortest path has not been computed yet.");
        }

        std::cout << "\n=== Dijkstra Shortest Path Result ===" << std::endl;
        std::cout << std::format("Start vertex: {}", graph.GetVertex(start_vid_)) << std::endl;
        PrintHelper(graph);
    }

    // ====================== 私有辅助：路径回溯 ======================
    std::vector<AM::Edge> Dijkstra::GetPathHelper(const AM& graph, int end_idx) const {
        std::vector<AM::Edge> path;
        // 边界处理：下标非法、不可达、起点自身
        if (end_idx < 0 || end_idx >= graph.GetVertexCount()
            || dist_[end_idx] == INF || end_idx == start_vid_) {
            return path;
        }

        // 🔙 从终点倒序回溯前驱，直到源点
        int curr = end_idx;
        while (curr != start_vid_) {
            int pre = prev_[curr];
            path.emplace_back(
                graph.GetVertex(pre),
                graph.GetVertex(curr),
                graph.GetWeightByIdx(pre, curr)
            );
            curr = pre;
        }

        // 🔄 反转路径，得到从源点到终点的正序路径
        std::reverse(path.begin(), path.end());
        return path;
    }

    // ====================== 私有辅助：Dijkstra核心算法 ======================
    void Dijkstra::ComputeHelper(const AM& graph, int start_idx) {
        int n = graph.GetVertexCount();
        // 🚩 访问标记数组：标记顶点最短路径是否已确定，算法结束自动销毁
        std::vector<bool> visited(n, false);

        for (int i = 0; i < n; ++i) {
            // 1. 🎯 贪心选择：找到距离源点最近的未访问顶点
            int min_dist = INF;
            int u_idx = -1;
            for (int j = 0; j < n; ++j) {
                if (!visited[j] && dist_[j] < min_dist) {
                    min_dist = dist_[j];
                    u_idx = j;
                }
            }
            if (u_idx == -1) break; // 所有可达顶点处理完毕，提前退出

            // 2. ✅ 标记顶点：该顶点的最短路径已最终确定
            visited[u_idx] = true;

            // 3. ⚡ 松弛操作：用当前顶点更新所有邻接点的最短距离
            for (int v_idx = 0; v_idx < n; ++v_idx) {
                if (!visited[v_idx]) {
                    int weight = graph.GetWeightByIdx(u_idx, v_idx);
                    // 仅当边存在、且经过u中转路径更短时，更新距离与前驱
                    if (weight != INF && dist_[u_idx] != INF
                        && dist_[u_idx] + weight < dist_[v_idx]) {
                        dist_[v_idx] = dist_[u_idx] + weight;
                        prev_[v_idx] = u_idx;
                    }
                }
            }
        }
    }

    // ====================== 私有辅助：打印结果 ======================
    void Dijkstra::PrintHelper(const AM& graph) const {
        int n = graph.GetVertexCount();
        for (int i = 0; i < n; ++i) {
            int vertex = graph.GetVertex(i);
            if (dist_[i] == INF) {
                std::cout << std::format("To vertex {}: unreachable", vertex) << std::endl;
            }
            else {
                std::cout << std::format("To vertex {}: distance = {}, path = ", vertex, dist_[i]);
                std::vector<AM::Edge> path = GetPathHelper(graph, i);

                if (path.empty()) {
                    std::cout << vertex << " (self)" << std::endl;
                }
                else {
                    std::cout << graph.GetVertex(start_vid_);
                    for (const auto& edge : path) {
                        std::cout << " -> " << edge.GetV();
                    }
                    std::cout << std::endl;
                }
            }
        }
    }

    // ====================== 测试函数 ======================
    void RunTest() {
        std::cout << "===== Dijkstra Shortest Path Test =====" << std::endl;
        try {
            int vertex_cnt, edge_cnt;
            std::cout << "Enter number of vertices and edges: ";
            if (!(std::cin >> vertex_cnt >> edge_cnt)
                || vertex_cnt <= 0 || edge_cnt <= 0) {
                throw std::invalid_argument("Invalid input: vertex and edge count must be positive integers.");
            }

            // 自动生成 0~n-1 的连续顶点编号，适配测试用例
            std::vector<int> vertices(vertex_cnt);
            for (int i = 0; i < vertex_cnt; ++i) {
                vertices[i] = i;
            }

            // 构建邻接矩阵图（内部循环输入m条边，格式u v weight）
            AM graph;
            graph.BuildGraph(vertex_cnt, edge_cnt, vertices.data());

            // 输入起点
            int start_vertex;
            std::cout << "Enter start vertex: ";
            if (!(std::cin >> start_vertex)) {
                throw std::invalid_argument("Invalid start vertex input.");
            }

            // 计算并打印最短路径结果
            Dijkstra sp;
            sp.ComputeSP(graph, start_vertex);
            sp.PrintSP(graph);
        }
        catch (const std::exception& e) {
            std::cerr << "\nError: " << e.what() << std::endl;
        }
    }

} // namespace shortest_path
```

## 九、⚠️ 高频考点与避坑指南

### 9.1 408 必考考点

1. Dijkstra 算法的时间复杂度（邻接矩阵$O(n^2)$，堆优化$O(elogn)$）
2. Dijkstra 不能处理负权边的原因
3. 手动模拟 Dijkstra 执行过程，写出每一轮的 dist 数组变化
4. Dijkstra 与 Prim 算法的异同（都是贪心选点，都是$O(n^2)$，但求解问题不同）
5. Dijkstra 与 BFS 的关系（BFS 是权值全为 1 的特殊 Dijkstra）

### 9.2 常见易错点

1. ❌ 标记时机错误：必须在选到顶点时就标记为已访问，不能等处理完邻接点再标记
2. ❌ 松弛条件遗漏：必须判断边存在（权值≠INF），否则加法会溢出
3. ❌ 负权图使用 Dijkstra：会得到错误的最短路径，负权图需要用 Bellman-Ford 或 SPFA
4. ❌ 混淆 Dijkstra 和 Floyd：Dijkstra 是单源，Floyd 是多源，时间复杂度$O(n^3)$
