## 一、📖 基础核心概念

### 1.1 有向无环图（DAG）

- **定义**：不存在环的有向图，全称 Directed Acyclic Graph，简称 **DAG 图**。
- **性质**：树形结构可以看作特殊的 DAG（无环且连通、边数为 n-1）；DAG 是描述工程、流程、依赖关系的标准数据模型。
- **应用场景**：可以用 DAG 表示项目、工程、任务流程，顶点表示活动，边表示先后依赖关系。

![拓扑排序 1.png](<../pict/拓扑排序 1.png>)

> 该 DAG 包含 6 个顶点 V1~V6，对应 AOV 网的 6 个活动，有向边表示活动先后依赖关系。

### 1.2 AOV 网

- **全称**：Activity On Vertex，用顶点表示活动的网。
- **定义**：用顶点表示活动，用有向边表示活动之间的先后次序的有向无环图。
    
    - 边 `u→v` 表示：活动 u 是活动 v 的前置活动，必须完成 u 才能开始 v。
    
- **性质**：AOV 网中绝对不能存在环，否则会出现活动循环依赖，永远无法完成。

### 1.3 拓扑序列

- **定义**：基于 AOV 网得出的一个顶点序列，是完成该 AOV 网所表示项目的合法先后顺序。
- **核心规则**：如果从顶点 vi 到顶点 vj 存在一条路径，那么在拓扑序列中，vi 一定排在 vj 之前。
- **性质**：**一个 DAG 的拓扑序列不一定唯一**。只要满足先后依赖关系，都是合法的拓扑序列。

### 1.4 拓扑排序

- **定义**：用于得出拓扑序列的算法 / 思路，称为拓扑排序。
- **核心逻辑**：如果要执行一个活动，必须保证其所有前置活动都已经完成。
    
    - 第一个可以执行的活动，一定是没有前置活动的顶点 → 也就是**入度为 0**的顶点。

## 二、🧠 Kahn 算法（入度表法）核心思想

### 2.1 核心贪心策略

拓扑排序的经典实现是**Kahn 算法**，基于贪心思想：

1. 每次选出当前所有入度为 0 的顶点，加入拓扑序列。
2. 移除该顶点及其所有出边，将它的邻接顶点的入度减 1。
3. 重复上述过程，直到所有顶点都加入序列，或剩余顶点都没有入度为 0 的（说明存在环）。

### 2.2 算法执行步骤（详细版）

1. **初始化**：
    
    - 引入入度数组 `ind[i]`，表示顶点 i 的入度。
    - 引入辅助队列（或栈），保存当前所有入度为 0 的顶点。
    - 初始化拓扑结果序列为空。
    
2. **统计入度**：遍历整张图的所有边，统计每个顶点的入度，存入入度数组。
3. **初始入队**：遍历入度数组，将所有初始入度为 0 的顶点加入队列。
4. **主循环处理**：
    
    1. 取出队首顶点 u，将 u 加入拓扑结果序列。
    2. 遍历顶点 u 的所有出边 `u→v`，将顶点 v 的入度减 1。
    3. 如果顶点 v 的入度减为 0，说明它的所有前置活动都已完成，将 v 加入队列。
    
5. **结果校验**：
    
    - 如果结果序列长度等于顶点总数，说明是合法 DAG，序列就是拓扑排序结果。
    - 如果结果序列长度小于顶点总数，说明图中存在环，无法进行拓扑排序。

## 三、⚡ 复杂度分析与存储选择

### 3.1 时间复杂度

- 基于**邻接表**存储的 Kahn 算法：
    
    - 统计入度：遍历所有顶点和边，总开销 O (n+e)
    - 每个顶点入队出队各 1 次，每条边被处理 1 次，总开销 O (n+e)
    - **总时间复杂度：O (n+e)**
    
- 基于邻接矩阵存储的 Kahn 算法：
    
    - 遍历每个顶点的邻接点需要扫完整行，总开销 O (n²)
    - **总时间复杂度：O (n²)**
    
- 结论：拓扑排序算法**天然适配邻接表存储**，稀疏图下效率远高于邻接矩阵。

### 3.2 空间复杂度

- 需要额外的入度数组 O (n)、辅助队列 O (n)、结果序列 O (n)
- **总空间复杂度：O (n)**

## 四、🔄 逆拓扑排序

### 4.1 定义

逆拓扑序列：要先做完所有的后置活动才能做该活动，序列顺序和拓扑序列刚好相反。

### 4.2 三种实现方法

1. **方法一：反转拓扑序列**
    
    - 先求出原图的拓扑序列，直接将序列反转，得到的就是逆拓扑序列。
    - 最简单直观，时间复杂度和拓扑排序一致。
    
2. **方法二：出度表法（反向 Kahn）**
    
    - 引入出度数组 `outd[i]`，表示顶点 i 的出度。
    - 引入辅助栈（或队列），保存出度为 0 的顶点。
    - 执行流程：
        
        1. 统计所有顶点的出度，初始出度为 0 的顶点入栈。
        2. 取出栈顶顶点 u，加入逆拓扑序列。
        3. 遍历 u 的所有入边，将对应前驱顶点的出度减 1，减到 0 则入栈。
        4. 循环直到栈空。
        
    
3. **方法三：反图拓扑法**
    
    - 建立原图的反向图（所有边方向反转）。
    - 对反图执行普通拓扑排序，得到的序列就是原图的逆拓扑序列。
    

### 4.3 补充：DFS 实现拓扑排序

除了 Kahn 算法，拓扑排序也可以用深度优先搜索 DFS 实现：

- 对 DAG 进行 DFS 遍历，顶点递归退出（回溯）的顺序，就是逆拓扑序列。
- 将逆拓扑序列反转，得到拓扑序列。
- 时间复杂度同样是 O (n+e)。

### ⚙️ 模块 2：核心算法实现（topological_sort.cpp）

```cpp
#include "topological_sort.h"
#include <iostream>
#include <stdexcept>
#include <format>
#include <queue>

namespace topological_sort {

    // ====================== 构造与析构 ======================
    TopologicalSort::TopologicalSort() noexcept
        : result_(), is_computed_(false)
    {
    }

    TopologicalSort::~TopologicalSort() noexcept {
        result_.clear();
    }

    // ====================== 公有核心接口 ======================
    void TopologicalSort::Compute(const AL& graph) {
        // 🔄 重置状态，支持多次重复调用
        result_.clear();
        is_computed_ = false;

        int vertex_cnt = graph.GetVertexCount();
        if (vertex_cnt <= 0) {
            throw std::invalid_argument("Compute failed: graph has no valid vertices.");
        }

        // 🚀 执行核心Kahn算法
        ComputeHelper(graph);

        // ✅ 结果校验：序列长度不等于顶点数 → 存在环，无法拓扑排序
        if (result_.size() != vertex_cnt) {
            throw std::runtime_error("Compute failed: graph contains cycles, cannot perform topological sort.");
        }

        is_computed_ = true;
    }

    void TopologicalSort::PrintResult() const {
        if (!is_computed_) {
            throw std::runtime_error("Print failed: topological sort has not been computed yet.");
        }

        std::cout << "\n=== Topological Sort Result ===" << std::endl;
        for (size_t i = 0; i < result_.size(); ++i) {
            if (i > 0) {
                std::cout << " -> ";
            }
            std::cout << result_[i];
        }
        std::cout << std::endl;
    }

    std::vector<char> TopologicalSort::GetResult() const {
        if (!is_computed_) {
            throw std::runtime_error("GetResult failed: topological sort has not been computed yet.");
        }
        return result_;
    }

    // ====================== 私有辅助：Kahn核心算法 ======================
    void TopologicalSort::ComputeHelper(const AL& graph) {
        int n = graph.GetVertexCount();

        // 📏 过程局部变量：入度数组、辅助队列，算法结束自动销毁，不污染对象状态
        std::vector<int> in_degree(n, 0);
        std::queue<int> q;

        // 第一步：统计所有顶点的入度
        for (int u = 0; u < n; ++u) {
            // 遍历顶点u的所有出边 u->v，顶点v的入度+1
            auto adj_edges = graph.GetAdjacentEdges(u);
            for (auto& edge : adj_edges) {
                int v = edge.first;
                in_degree[v]++;
            }
        }

        // 第二步：所有入度为0的顶点入队
        for (int i = 0; i < n; ++i) {
            if (in_degree[i] == 0) {
                q.push(i);
            }
        }

        // 第三步：Kahn算法主循环
        while (!q.empty()) {
            int u = q.front();
            q.pop();

            // 将当前顶点加入拓扑序列
            result_.push_back(graph.GetVertex(u));

            // 遍历所有出边，更新邻接点的入度
            auto adj_edges = graph.GetAdjacentEdges(u);
            for (auto& edge : adj_edges) {
                int v = edge.first;
                in_degree[v]--;
                // 入度减为0则入队
                if (in_degree[v] == 0) {
                    q.push(v);
                }
            }
        }
    }

    // ====================== 测试函数（适配6顶点8边用例） ======================
    void runTest() {
        std::cout << "===== Topological Sort Test =====" << std::endl;
        try {
            int vertex_cnt, edge_cnt;
            std::cout << "Enter number of vertices and edges: ";
            if (!(std::cin >> vertex_cnt >> edge_cnt) || vertex_cnt <= 0 || edge_cnt < 0) {
                throw std::invalid_argument("Invalid input: vertex count must be positive, edge count must be non-negative.");
            }

            // 输入顶点序列
            char vertices[105];
            std::cout << "Enter " << vertex_cnt << " vertices (continuous characters): ";
            std::cin >> vertices;

            // 先初始化顶点，再手动插入有向边
            AL graph;
            graph.BuildDirectedGraph(vertex_cnt, edge_cnt, vertices);

            // 计算并打印拓扑排序结果
            TopologicalSort ts;
            ts.Compute(graph);
            ts.PrintResult();
        }
        catch (const std::exception& e) {
            std::cerr << "\nError: " << e.what() << std::endl;
        }
    }

} // namespace topological_sort
```

## 六、🎓 408 高频考点与避坑指南

### 6.1 核心考点速记

1. **适用前提**：拓扑排序只能用于**有向无环图（DAG）**，有环图无法得到合法拓扑序列。
2. **序列性质**：DAG 的拓扑序列**不唯一**，只要满足先后依赖关系都是合法的。
3. **经典算法**：Kahn 算法（入度表法）是最常考的拓扑排序实现，邻接表下时间复杂度 O (n+e)。
4. **判环作用**：拓扑排序可以用来判断有向图是否存在环 —— 若拓扑序列顶点数小于总顶点数，则图有环。
5. **应用场景**：任务调度、课程安排、编译依赖、工程流程规划等。

### 6.2 常见易错点

1. ❌ 混淆无向图和有向图：拓扑排序是**有向图**的算法，无向图没有拓扑排序的概念。
2. ❌ 认为拓扑序列唯一：只要不破坏依赖顺序，顺序可以变化，只有严格线性依赖的 DAG 才有唯一拓扑序列。
3. ❌ 忽略环的判断：算法结束后必须校验结果长度，否则有环的图会得到不完整的序列。
4. ❌ 邻接矩阵复杂度记错：邻接表实现是 O (n+e)，邻接矩阵是 O (n²)，不要混淆。
