## 一、B 树基础性质📚

B 树 = **多路平衡查找树**，阶数 m 约束所有结点形态。先明确两类易混淆的结点概念：

- 🟢 **终端结点**：位于树的最底层，是实际存储关键字的结点，没有子结点；插入、删除的实际操作都发生在终端结点。
- ⚪ **叶子结点（失败结点）**：终端结点的空孩子，不存储任何关键字与数据，仅用来标记查找失败的位置。

核心性质如下：

1. 最多 $m$ 个孩子，最多 $(m-1)$ 个关键字
2. 除根、叶子外，结点至少 $\lceil m/2 \rceil$ 个孩子，最少 $\lceil m/2 \rceil - 1$ 个关键字
3. 结点内部关键字严格升序；$n$ 个关键字对应 $(n+1)$ 棵子树
4. ✅ 所有叶子结点处于同一层，天然平衡，保证查找 / 插入 / 删除复杂度 $O(\log n)$

```cpp
/**
 * @file BTree.h
 * @brief B树（B-Tree）模块文件——只包含类的声明（接口）。
 *
 * ============================ B树的数据结构性质 ============================
 * B树是一棵“多路平衡查找树”，用一个参数 m（阶）描述它的形状约束：
 *
 *   1. 【孩子数上限】每个结点最多有 m 个孩子      => 最多有 m-1 个关键字。
 *   2. 【孩子数下限】除根结点和叶结点外，
 *      每个结点至少有 ceil(m/2) 个孩子           => 至少有 ceil(m/2)-1 个关键字。
 *      （根结点特殊：如果根不是叶子，至少要有 2 个孩子；
 *        如果整棵树只有根这一个结点，根可以只有 0~m-1 个关键字，不受下限约束。）
 *   3. 【有序性】每个结点内部的关键字严格升序排列：
 *         keys[0] < keys[1] < ... < keys[n-1]
 *      这保证了可以在结点内部用顺序查找/二分查找定位。
 *   4. 【指针与关键字的对应关系】非叶结点若有 n 个关键字，则一定有 n+1 个孩子指针，
 *      其中 children[i] 这棵子树中的所有关键字 x 满足：
 *         keys[i-1] < x < keys[i]     （children[0] 对应 -∞ < x < keys[0]，
 *                                        children[n] 对应 keys[n-1] < x < +∞）
 *   5. 【高度平衡】所有叶结点都出现在同一层。这是 B 树能保证
 *      O(log n) 查找/插入/删除复杂度的根本原因——树不会因为局部插入而“长歪”。
 *
 * 本文件采用 “命名空间 + 类” 的组织方式：
 *   - 命名空间 BTreeADT 隔离本模块的符号，避免与外部代码命名冲突；
 *   - 类 BTree 内部用 public/private 严格区分：
 *       public  ：对外的“契约”接口，负责参数合法性检查、结果的边界处理，
 *                 以及把工作转交给合适的私有 helper；
 *       private ：Node 结点结构 + 真正实现查找/插入循环分裂上传/
 *                 删除借位合并等核心算法逻辑的 helper 函数。
 *   外部使用者只需要认识 public 接口，不需要（也不应该）关心内部是怎么分裂、
 *   怎么合并的——这正是面向对象“封装”的意义所在。
 * ===========================================================================
 */

#ifndef BTREE_ADT_H
#define BTREE_ADT_H

#include <vector>
#include <string>
#include <iostream>

namespace BTreeADT {

    /**
     * @brief B树中关键字的类型。
     *
     * 这里用别名而不是写死 int，是为了让“将来想换成 double / string 之类的
     * 可比较类型”这件事只需要改一行代码。如果需要同时支持多种类型共存，
     * 可以把 BTree 改造成 template<typename KeyType> class BTree，
     * 那样就需要把实现也搬回头文件（或做显式实例化），
     * 本教学版本为了让“接口 / 实现 / main 三文件分离”这件事更直观，
     * 选择了非模板 + 类型别名的写法。
     */
    using KeyType = int;

    /**
     * @class BTree
     * @brief B树容器：支持 search / insert / remove / print 等操作。
     *
     * 内部固定一个阶数 m（构造时传入，之后不可修改），
     * 所有结点关键字个数的上下限都从 m 推导出来，
     * 避免把 “m-1”“ceil(m/2)-1” 这类魔法数字散落在各处实现里。
     */
    class BTree {
    public:
        /**
         * @brief 构造一棵空的 B 树。
         * @param order B树的阶 m（每个结点最多 m 个孩子）。要求 m >= 3，
         *              否则 ceil(m/2) < 2，非根结点将连“借位”的意义都没有了。
         * @throws std::invalid_argument 当 order < 3 时抛出。
         */
        explicit BTree(int order);

        /// 析构：递归释放所有结点，防止内存泄漏。
        ~BTree();

        // 教学用容器，不实现深拷贝语义，直接禁用拷贝，避免意外的浅拷贝导致
        // 两个 BTree 对象共享/重复释放同一批结点指针。
        BTree(const BTree&) = delete;
        BTree& operator=(const BTree&) = delete;

    private:
        /**
         * @struct Node
         * @brief B树的结点。
         *
         * 关键字数组与孩子指针数组的大小关系是 B 树最核心的不变量：
         *   非叶结点：children.size() == keys.size() + 1
         *   叶结点  ：children.size() == 0（叶结点没有孩子，这也是查找/插入的终止条件）
         *
         * parent 指针是本实现的一个关键设计：
         *   讲义中“回溯插入法”需要一个 pre 指针记录父亲结点以便向上分裂/调整；
         *   与其在插入/删除时额外维护一个“路径栈”，不如直接让每个结点自己
         *   保存双亲指针，这样插入的“循环分裂上传”可以写成一个纯 while 循环，
         *   而不需要显式的栈或递归——这正是双亲指针存在的意义。
         */
        struct Node {
            std::vector<KeyType> keys;     ///< 关键字数组，严格升序
            std::vector<Node*> children;   ///< 孩子指针数组（叶结点为空）
            Node* parent;                  ///< 双亲指针，根结点为 nullptr
            bool leaf;                     ///< 是否为叶结点

            explicit Node(bool isLeaf) : parent(nullptr), leaf(isLeaf) {}
        };

        Node* root; ///< 根指针，空树时为 nullptr
        int m;      ///< B树的阶

        // ---------------- 由阶数 m 推导出的容量常量（集中计算，杜绝魔法数字）----------------
        int maxKeys() const { return m - 1; }              ///< 任意结点关键字个数上限
        int minKeys() const { return (m + 1) / 2 - 1; }    ///< 非根结点关键字个数下限 = ceil(m/2)-1
```

># 模块 1️⃣ 查找功能 🔍

## 原理讲解

1. 从根结点开始，在当前结点内顺序（或二分）遍历关键字；
2. 命中关键字：查找成功；
3. 未命中：找到第一个大于目标关键字的位置，向下进入对应子树；
4. 抵达叶子结点仍未找到 → 查找失败。

## 对应代码

>### BTree.h 查找相关声明

```cpp
        // ==================== 查找：私有 helper ====================

        /**
         * @brief 在单个结点内部定位 key。
         *
         * 对应讲义：“先在结点内部进行顺序查找（折半查找），找第一个大于等于 x 的位置 i”。
         * @param[out] idx   若命中，idx 为命中下标；若未命中，idx 为“应该继续深入的孩子下标”
         *                   （即 children[idx] 这棵子树，因为 keys[idx] 是第一个 > key 的关键字，
         *                    key 必然落在它左边那棵子树里）。
         * @param[out] found 是否命中。
         */
        void locateInNode(Node* node, KeyType key, int& idx, bool& found) const;

        /// 从根出发查找 key，命中则返回结点指针并通过 idx 带回下标，否则返回 nullptr。
        Node* searchHelper(KeyType key, int& idx) const;

    public:
        /**
         * @brief 查找关键字 key 是否存在。
         * @return true 表示存在。
         */
        bool search(KeyType key) const;

        /**
         * @brief 查找关键字 key，并把命中位置的描述信息写入 locationDesc
         *        （对应讲义里“返回位置《结点p地址，数据数组的下标i》”的教学展示版本）。
         * @return true 表示找到。
         */
        bool search(KeyType key, std::string& locationDesc) const;
```

>### BTree.cpp 查找实现

```cpp
    // ============================================================================
    // 查找
    // ============================================================================

    void BTree::locateInNode(Node* node, KeyType key, int& idx, bool& found) const {
        // 结点内关键字升序排列，这里用顺序查找演示（数据量大时可换成二分查找，
        // 二分查找不改变“找第一个 >= key 的位置”这一语义，只是更快）。
        int i = 0;
        int n = static_cast<int>(node->keys.size());
        while (i < n && key > node->keys[i]) {
            ++i;
        }
        if (i < n && node->keys[i] == key) {
            found = true;
            idx = i;               // 命中：数据下标就是 i
        }
        else {
            found = false;
            idx = i;                // 未命中：应到 children[i] 这棵左子树里继续找
        }
    }

    BTree::Node* BTree::searchHelper(KeyType key, int& idx) const {
        Node* cur = root;
        while (cur != nullptr) {
            bool found;
            locateInNode(cur, key, idx, found);
            if (found) {
                return cur;
            }
            if (cur->leaf) {
                // 已经走到叶结点仍未命中，说明 key 不在树中
                // （叶结点没有孩子，无法再往下走，这正是查找失败的判定条件）。
                return nullptr;
            }
            cur = cur->children[idx];
        }
        return nullptr;
    }

    bool BTree::search(KeyType key) const {
        int idx;
        return searchHelper(key, idx) != nullptr;
    }

    bool BTree::search(KeyType key, std::string& locationDesc) const {
        int idx;
        Node* node = searchHelper(key, idx);
        if (node == nullptr) {
            locationDesc = "未找到";
            return false;
        }
        std::ostringstream oss;
        oss << "命中结点地址=" << static_cast<const void*>(node)
            << ", 数据下标 i=" << idx << ", 该结点关键字=[";
        for (size_t k = 0; k < node->keys.size(); ++k) {
            oss << node->keys[k];
            if (k + 1 < node->keys.size()) oss << " ";
        }
        oss << "]";
        locationDesc = oss.str();
        return true;
    }
```

># 模块 2️⃣ 插入功能 ➕

## 原理讲解

1. 向下遍历找到**合适的叶子结点**作为插入位置；
2. 将关键字有序插入结点；
3. 插入后若关键字数量超出上限 \(m-1\) → **结点溢出**；
4. 分裂规则：以 \(\lceil m/2 \rceil\) 位置分割结点，中间关键字**向上提升到父结点**；
5. 提升后父结点可能再次溢出，**循环向上分裂**；
6. 若根结点溢出，新建根结点，树的高度 + 1。

## 对应代码

>### BTree.h 插入相关声明

```cpp
        // ==================== 插入：私有 helper ====================

        /// 对应讲义中的 “pre 指针”：从根出发一路向下，最终返回 key 应该插入的那个叶结点。
        Node* findLeafForInsert(KeyType key) const;

        /**
         * @brief 把 key 按升序插入 node->keys 的正确位置；如果 rightChild 非空，
         *        同时把 rightChild 插入 node->children 中“key 右侧”的孩子槽位。
         *
         * 这个函数同时服务于两种场景：
         *   (1) 插入到叶结点：只插入 key，rightChild 传 nullptr；
         *   (2) 分裂后把“提升关键字”插入父结点：key 和新裂出的右兄弟 rightChild 一起插入。
         */
        void insertKeyIntoNode(Node* node, KeyType key, Node* rightChild);

        /**
         * @brief 循环分裂上传（本实现的核心算法，严格对应讲义描述）。
         *
         * 从 startNode（刚插入完毕、关键字数可能已经等于 m 的结点）出发：
         *   while 当前结点关键字数 > m-1（即等于 m，说明溢出了）：
         *       按下标 s = ceil(m/2) 分裂成左右两个结点，中间的 data[s] 提升；
         *       若当前结点是根，新建一个根装下这个提升的关键字，循环结束；
         *       否则把提升的关键字连同新裂出的右结点一起插入父结点，
         *       当前结点上移为父结点，继续检查父结点是否也溢出。
         *
         * 这就是“循环”二字的含义：溢出可能像多米诺骨牌一样一路传导到根，
         * 但每一层最多分裂一次，循环次数不会超过树高，整体仍是 O(log n)。
         */
        void splitAndPromoteLoop(Node* startNode);

        /**
         * @brief 把一个已经溢出（关键字数 == m）的结点从中间断开。
         *
         * 对应讲义：
         *   “从下标 s=ceil(m/2) 位置分开，data[1]~~data[s-1] 留在原结点，
         *    data[s] 插入到父亲结点中，data[s+1]~~data[m] 给新结点 ap，
         *    同时每个数据对应的左右孩子也要给 ap”
         *
         * @param node        待分裂的结点（分裂后复用为左半部分）。
         * @param[out] rightOut   新裂出的右半部分结点。
         * @param[out] promotedKey 需要上传给父结点的关键字。
         */
        void splitChild(Node* node, Node*& rightOut, KeyType& promotedKey);

    public:
        /**
         * @brief 插入关键字 key（默认约定：树中不存在重复关键字）。
         *        算法：先找到应插入的叶结点，插入后若关键字数超过上限 m-1，
         *        则执行“循环分裂上传”，直到不再溢出或分裂到根为止。
         */
        void insert(KeyType key);
```

>### BTree.cpp 插入实现

```cpp
    // ============================================================================
    // 插入：回溯插入法 + 循环分裂上传
    // ============================================================================

    BTree::Node* BTree::findLeafForInsert(KeyType key) const {
        // 从根一路向下走到叶结点为止；沿途不需要额外维护路径栈，
        // 因为每个结点自己保存了 parent 指针，将来分裂时可以直接向上回溯。
        Node* cur = root;
        while (!cur->leaf) {
            int idx; bool found;
            locateInNode(cur, key, idx, found);
            cur = cur->children[idx];
        }
        return cur;
    }

    void BTree::insertKeyIntoNode(Node* node, KeyType key, Node* rightChild) {
        // 简单插入排序的思路：从后往前找位置，边比较边挪动。
        int i = static_cast<int>(node->keys.size()) - 1;
        node->keys.push_back(key); // 先占一个位置，下面再把它挪到正确的地方
        while (i >= 0 && node->keys[i] > key) {
            node->keys[i + 1] = node->keys[i];
            --i;
        }
        int insertPos = i + 1; // key 最终落在 keys[insertPos]
        node->keys[insertPos] = key;

        if (rightChild != nullptr) {
            // rightChild 是“新提升的关键字”右侧那棵子树，
            // 按照“children[i] 对应 keys[i-1] 与 keys[i] 之间”的规则，
            // 它应该插入到 children[insertPos + 1] 这个槽位。
            node->children.insert(node->children.begin() + insertPos + 1, rightChild);
            rightChild->parent = node;
        }
    }

    void BTree::splitChild(Node* node, Node*& rightOut, KeyType& promotedKey) {
        // 此时 node->keys.size() 应该恰好等于 m（临时超过上限 1 个）。
        int s = (m + 1) / 2;        // s = ceil(m/2)，讲义里的分裂点（1-indexed）
        int promotedIdx = s - 1;    // 换算成 0-indexed 下标

        promotedKey = node->keys[promotedIdx];

        Node* right = new Node(node->leaf);

        // data[s+1] ~ data[m] 划给新结点（0-indexed: promotedIdx+1 .. end）
        right->keys.assign(node->keys.begin() + promotedIdx + 1, node->keys.end());

        if (!node->leaf) {
            // 非叶结点分裂时，孩子指针要跟着对应的关键字一起走，
            // 并且别忘了把这些孩子的 parent 指针指向新家（right）。
            right->children.assign(node->children.begin() + promotedIdx + 1,
                node->children.end());
            for (Node* child : right->children) {
                child->parent = right;
            }
            node->children.resize(promotedIdx + 1); // 左半部分保留前 s 个孩子
        }

        // data[1] ~ data[s-1] 留在原结点（0-indexed: 0 .. promotedIdx-1）
        node->keys.resize(promotedIdx);

        rightOut = right;
    }

    void BTree::splitAndPromoteLoop(Node* startNode) {
        Node* current = startNode;

        // 只要当前结点关键字数超过上限 m-1（也就是恰好等于 m），就必须分裂。
        // 分裂可能一路向上传导到根，这就是“循环”的含义。
        while (static_cast<int>(current->keys.size()) > maxKeys()) {
            Node* right = nullptr;
            KeyType promoted;
            splitChild(current, right, promoted); // current 复用为分裂后的左半部分

            if (current == root) {
                // 溢出传导到了根：必须新增一层，用一个新根装下被提升的关键字。
                Node* newRoot = new Node(false);
                newRoot->keys.push_back(promoted);
                newRoot->children.push_back(current);
                newRoot->children.push_back(right);
                current->parent = newRoot;
                right->parent = newRoot;
                root = newRoot;
                break; // 根分裂之后，整棵树不会再有结点溢出，循环自然结束
            }

            // 非根：把提升的关键字和新裂出的右结点一起塞进父结点，
            // 父结点关键字个数因此 +1，可能自己也溢出，于是把 current 上移继续检查。
            Node* parent = current->parent;
            insertKeyIntoNode(parent, promoted, right);
            current = parent;
        }
    }

    void BTree::insert(KeyType key) {
        if (root == nullptr) {
            // 空树：直接新建一个叶结点作为根。
            root = new Node(true);
            root->keys.push_back(key);
            return;
        }

        // 题目约定“默认不存在重复数据”，这里做一次防御性查重，
        // 避免重复插入破坏“同一叶结点内关键字唯一”的假设。
        int existingIdx;
        if (searchHelper(key, existingIdx) != nullptr) {
            return; // 已存在，按约定不重复插入
        }

        Node* leaf = findLeafForInsert(key); // 对应讲义中的“pre 指针”定位到的结点
        insertKeyIntoNode(leaf, key, nullptr);

        // 插入后该叶结点关键字数可能达到 m（临时越过上限），
        // 交给“循环分裂上传”统一处理后续调整。
        splitAndPromoteLoop(leaf);
    }
```

># 模块 3️⃣ 删除功能 ➖

## 原理讲解

删除分为两大类场景：

1. **待删关键字在叶子结点**：直接移除关键字；移除后检查结点关键字数量是否低于下限（下溢）
2. **待删关键字在非叶子结点**：
    
    - 优先取**中序前驱 / 后继关键字**覆盖待删关键字，转化为叶子结点删除问题
    
3. 结点下溢修复策略（优先级从高到低）：
    
    ✅ 向左右富裕兄弟**借关键字**（必须通过父结点中转，维持有序性）
    
    ❌ 无法借用 → **合并结点**：父结点分隔关键字下移，两个兄弟结点合并；
4. 合并会造成父结点关键字减少，下溢向上循环传导；
5. 特殊边界：根结点关键字清空，根的唯一孩子晋升为新根，树高度 - 1。

## 对应代码

>### BTree.h 删除相关声明

```cpp
        // ==================== 删除：私有 helper ====================

        /// 从 node 出发递归地删除 key（node 的子树中必然包含 key，由外层保证）。
        void removeHelper(Node* node, KeyType key);

        /// 情况1：z 是叶结点，直接从 keys 数组中移除下标 idx 处的关键字。
        void removeFromLeaf(Node* node, int idx);

        /**
         * @brief 情况2：z 是非叶结点，删除 node->keys[idx]。
         *
         * 优先从“关键字个数有富余（> 下限）”的那个孩子借一个前驱/后继值来覆盖 key，
         * 这是对讲义思路的一个常见工程优化（讲义里固定用后继，这里优先挑“富余”的一侧，
         * 目的是尽量减少不必要的合并操作）；如果左右孩子都恰好在下限，
         * 就退化为讲义描述的做法：合并两个孩子与 key，再到合并后的结点里递归删除。
         */
        void removeFromInternal(Node* node, int idx);

        /// 取 node->children[idx] 这棵子树中最大的关键字（中序前驱）。
        KeyType getPredecessorKey(Node* node, int idx) const;

        /// 取 node->children[idx+1] 这棵子树中最小的关键字（中序后继）。
        KeyType getSuccessorKey(Node* node, int idx) const;

        /**
         * @brief 修复下溢：parent->children[childIdx] 的关键字个数已经低于下限。
         *
         * 依次尝试：
         *   (1) 向左兄弟借（左兄弟关键字数 > 下限）；
         *   (2) 向右兄弟借（右兄弟关键字数 > 下限）；
         *   (3) 都不够借 —— 与某个兄弟合并（同时把父结点中对应的分隔关键字下移）。
         * 合并会使 parent 自身的关键字数减少 1，
         * 这个连锁反应由调用者（removeHelper 的递归返回路径）继续向上检查处理，
         * 这就是讲义所说的“循环向上调整，直到某个结点不需要调整或到达根”。
         */
        void fixUnderflow(Node* parent, int childIdx);

        /// 从左兄弟借一个关键字（借关键字要“通过父亲结点”中转，保证顺序性）。
        void borrowFromLeftSibling(Node* parent, int idx);

        /// 从右兄弟借一个关键字（同上，方向相反）。
        void borrowFromRightSibling(Node* parent, int idx);

        /**
         * @brief 合并 parent->children[idx] 与 parent->children[idx+1]，
         *        并把 parent->keys[idx] 这个分隔关键字下移作为两者的“粘合剂”。
         *        合并后 parent 少一个关键字、少一个孩子指针。
         */
        void mergeWithSibling(Node* parent, int idx);

    public:
        /**
         * @brief 删除关键字 key。
         * @return true 表示删除成功；false 表示 key 本不存在，无需删除。
         */
        bool remove(KeyType key);
```

>### BTree.cpp 删除实现

```cpp
    // ============================================================================
    // 删除：找到 z 所在结点 -> 分类处理 -> 借位/合并 -> 循环向上调整
    // ============================================================================

    KeyType BTree::getPredecessorKey(Node* node, int idx) const {
        // 前驱 = node->children[idx] 这棵子树中最大的关键字，
        // 一路向右孩子走到底（叶结点）即可取到。
        Node* cur = node->children[idx];
        while (!cur->leaf) {
            cur = cur->children.back();
        }
        return cur->keys.back();
    }

    KeyType BTree::getSuccessorKey(Node* node, int idx) const {
        // 后继 = node->children[idx+1] 这棵子树中最小的关键字，
        // 一路向左孩子走到底（叶结点）即可取到。
        Node* cur = node->children[idx + 1];
        while (!cur->leaf) {
            cur = cur->children.front();
        }
        return cur->keys.front();
    }

    void BTree::removeFromLeaf(Node* node, int idx) {
        // 情况1：z 是叶结点，孩子都是空孩子，直接从数组中移除即可，
        // 不需要对孩子做任何处理（讲义原话）。
        node->keys.erase(node->keys.begin() + idx);
    }

    void BTree::removeFromInternal(Node* node, int idx) {
        KeyType key = node->keys[idx];
        Node* leftChild = node->children[idx];
        Node* rightChild = node->children[idx + 1];

        if (static_cast<int>(leftChild->keys.size()) > minKeys()) {
            // 左孩子富余：用中序前驱覆盖 key，问题转化为在左子树中删除前驱
            // （这与讲义描述的“用后继覆盖”是对称的思路，都是把情况2转化为情况1）。
            KeyType pred = getPredecessorKey(node, idx);
            node->keys[idx] = pred;
            removeHelper(leftChild, pred);
            if (static_cast<int>(leftChild->keys.size()) < minKeys()) {
                fixUnderflow(node, idx);
            }
        }
        else if (static_cast<int>(rightChild->keys.size()) > minKeys()) {
            // 右孩子富余：讲义描述的标准做法——
            // 找 x 的中序后继 x1（一定在某个叶结点 k 中），用 x1 覆盖 x，
            // 问题转化为去 k 中删除 x1，也就是情况1。
            KeyType succ = getSuccessorKey(node, idx);
            node->keys[idx] = succ;
            removeHelper(rightChild, succ);
            if (static_cast<int>(rightChild->keys.size()) < minKeys()) {
                fixUnderflow(node, idx + 1);
            }
        }
        else {
            // 左右孩子的关键字数都恰好在下限，借了就会导致对方下溢，
            // 只能合并：把 leftChild、key、rightChild 三者合并成一个结点，
            // 再到合并后的结点中递归删除 key。
            mergeWithSibling(node, idx);
            removeHelper(node->children[idx], key);
            if (static_cast<int>(node->children[idx]->keys.size()) < minKeys()) {
                fixUnderflow(node, idx);
            }
        }
    }

    void BTree::removeHelper(Node* node, KeyType key) {
        int idx; bool found;
        locateInNode(node, key, idx, found);

        if (found) {
            if (node->leaf) {
                removeFromLeaf(node, idx);       // 情况1
            }
            else {
                removeFromInternal(node, idx);   // 情况2
            }  
            return;
        }

        // key 不在当前结点里，继续向 children[idx] 这棵子树深入
        // （调用者已经保证 key 一定存在于树中，所以这里 node 不可能是叶结点）。
        Node* child = node->children[idx];
        removeHelper(child, key);

        // 递归返回后检查刚才处理过的孩子是否下溢，
        // 这正是讲义所说的“循环向上调整”，只是这里用函数递归的返回路径
        // 天然实现了“从下往上、逐层检查”的效果。
        if (static_cast<int>(child->keys.size()) < minKeys()) {
            fixUnderflow(node, idx);
        }
    }

    void BTree::borrowFromLeftSibling(Node* parent, int idx) {
        Node* child = parent->children[idx];
        Node* leftSib = parent->children[idx - 1];

        // 借关键字必须“通过父亲结点中转”才能维持全局有序性（讲义强调的这一点）：
        // 父结点中的分隔关键字下移，成为 child 的新的第一个关键字；
        // 左兄弟中最大的关键字上移，填补父结点腾出来的位置。
        child->keys.insert(child->keys.begin(), parent->keys[idx - 1]);
        parent->keys[idx - 1] = leftSib->keys.back();
        leftSib->keys.pop_back();

        if (!child->leaf) {
            // 孩子指针要跟着“过继”的关键字一起挪动，指向左兄弟最右侧的那棵子树，
            // 现在归 child 管，插到 child 的最前面。
            child->children.insert(child->children.begin(), leftSib->children.back());
            child->children.front()->parent = child;
            leftSib->children.pop_back();
        }
    }

    void BTree::borrowFromRightSibling(Node* parent, int idx) {
        Node* child = parent->children[idx];
        Node* rightSib = parent->children[idx + 1];

        // 与左借对称：父结点的分隔关键字下移到 child 末尾，
        // 右兄弟中最小的关键字上移填补父结点。
        child->keys.push_back(parent->keys[idx]);
        parent->keys[idx] = rightSib->keys.front();
        rightSib->keys.erase(rightSib->keys.begin());

        if (!child->leaf) {
            child->children.push_back(rightSib->children.front());
            child->children.back()->parent = child;
            rightSib->children.erase(rightSib->children.begin());
        }
    }

    void BTree::mergeWithSibling(Node* parent, int idx) {
        Node* left = parent->children[idx];
        Node* right = parent->children[idx + 1];

        // 父结点对应的分隔关键字下移，充当 left 与 right 之间的“黏合剂”，
        // 之后 right 的全部关键字、孩子指针依次接到 left 后面。
        left->keys.push_back(parent->keys[idx]);
        left->keys.insert(left->keys.end(), right->keys.begin(), right->keys.end());

        if (!left->leaf) {
            left->children.insert(left->children.end(),
                right->children.begin(), right->children.end());
            for (Node* c : left->children) {
                c->parent = left; // 统一刷新父指针，保证一致性
            }
        }

        // 父结点删除分隔关键字，以及指向 right 的孩子指针；
        // 父结点从此少一个关键字——这正是下溢会向上传导的原因。
        parent->keys.erase(parent->keys.begin() + idx);
        parent->children.erase(parent->children.begin() + idx + 1);

        delete right;
    }

    void BTree::fixUnderflow(Node* parent, int childIdx) {
        bool hasLeftSibling = childIdx > 0;
        bool hasRightSibling = childIdx < static_cast<int>(parent->children.size()) - 1;

        // 优先级：先尝试“借”，借不到才“合并”——
        // 借操作是 O(1) 的局部调整，合并会让下溢向上传导，能借就不合并。
        if (hasLeftSibling &&
            static_cast<int>(parent->children[childIdx - 1]->keys.size()) > minKeys()) {
            borrowFromLeftSibling(parent, childIdx);
        }
        else if (hasRightSibling &&
            static_cast<int>(parent->children[childIdx + 1]->keys.size()) > minKeys()) {
            borrowFromRightSibling(parent, childIdx);
        }
        else if (hasLeftSibling) {
            // 都不够借：与左兄弟合并（合并 [childIdx-1] 和 [childIdx]）
            mergeWithSibling(parent, childIdx - 1);
        }
        else {
            // 没有左兄弟，只能与右兄弟合并（合并 [childIdx] 和 [childIdx+1]）
            mergeWithSibling(parent, childIdx);
        }
        // 注意：合并会让 parent 自己的关键字数 -1，
        // parent 是否也需要继续向上调整，由 removeHelper 递归返回到
        // 上一层时自动检查（parent 本身也是某个更高层结点的孩子）。
    }

    bool BTree::remove(KeyType key) {
        if (root == nullptr) {
            return false; // 空树，无需删除
        }
        int idx;
        if (searchHelper(key, idx) == nullptr) {
            return false; // key 本不存在
        }

        removeHelper(root, key);

        // 特殊收尾：根结点因为“唯一的分隔关键字被合并掉”而变空时，
        // 它唯一剩下的孩子晋升为新的根，树高整体减一
        // （讲义原话：“合并后根结点唯一的一个孩子做新的根结点”）。
        if (root->keys.empty()) {
            Node* oldRoot = root;
            if (root->leaf) {
                root = nullptr; // 树被删空了
            }
            else {
                root = root->children[0];
                root->parent = nullptr;
            }
            delete oldRoot;
        }
        return true;
    }
```

```cpp
    // 打印（教学辅助：直观展示树的层次结构）
    // ============================================================================

    void BTree::printLevelOrder(std::ostream& os) const {
        if (root == nullptr) {
            os << "(空树)\n";
            return;
        }
        std::queue<Node*> q;
        q.push(root);
        int level = 0;
        while (!q.empty()) {
            int levelSize = static_cast<int>(q.size());
            os << "第" << level << "层: ";
            for (int i = 0; i < levelSize; ++i) {
                Node* node = q.front();
                q.pop();
                os << "[";
                for (size_t k = 0; k < node->keys.size(); ++k) {
                    os << node->keys[k];
                    if (k + 1 < node->keys.size()) os << " ";
                }
                os << "]";
                if (i + 1 < levelSize) os << " ";
                if (!node->leaf) {
                    for (Node* c : node->children) q.push(c);
                }
            }
            os << "\n";
            ++level;
        }
    }

    void BTree::print() const {
        printLevelOrder(std::cout);
```
