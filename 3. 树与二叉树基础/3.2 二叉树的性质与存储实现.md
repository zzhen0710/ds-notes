### 📌 核心定义：什么是二叉树？

**二叉树**是**n (n≥0) 个结点构成的有限集合**，是一种**每个结点最多拥有两棵子树的特殊有序树**，核心特性是**递归性**与**左右子树的有序性**。

- ❌ **空树**：n=0 时，树中没有任何结点，称为空二叉树。
    
- ✅ **非空二叉树的核心规则（n>0）**：
    
    1. 🌱 有且仅有一个**根结点（Root）**，是整棵树的起点。
    2. 除根结点外，其余结点分为**最多两个互不相交的有限集**，分别称为该结点的**左子树**和**右子树**，左右子树本身也是符合定义的二叉树。
    3. 🔴 左右子树有严格的顺序，即使结点只有一棵子树，也必须明确区分是左子树还是右子树，调换顺序会成为一棵全新的二叉树。
    
- 🔍 与普通树 / 度为 2 的有序树的核心区别：

|特性|二叉树|度为 2 的有序树|
|:--|:--|:--|
|结点度上限|最多 2 个|最多 2 个|
|单孩子结点|必须区分左 / 右孩子|无需区分左右顺序|
|空树合法性|允许空树|至少有一个结点度为 2，不能为空树|

### 🔑 二叉树的核心术语（特殊二叉树，408 高频考点）

#### 🌳 满二叉树

- 定义：每一层的结点数都达到该层的最大上限，除叶子结点外，所有结点都有左右两个孩子，且所有叶子结点都集中在最后一层。
- 核心特性：深度为 h 的满二叉树，总结点数固定为 2h−1，不存在度为 1 的结点，是完全二叉树的特殊情况。

#### 📐 完全二叉树

- 定义：对满二叉树从 1 开始按层序编号，从最大编号开始向前连续删除若干结点后得到的二叉树，其结点编号与同深度的满二叉树一一对应。
- 核心考点特性：
    
    1. 叶子结点只能出现在最后两层，最后一层的叶子结点全部靠左连续排列。
    2. 度为 1 的结点最多只有 1 个，且该结点只有左孩子，无右孩子。
    3. 若结点编号 i > n/2，则该结点一定是叶子结点。
    

#### 📐 斜树

- 定义：所有结点都只有左子树的二叉树称为**左斜树**，所有结点都只有右子树的二叉树称为**右斜树**。
- 核心特性：深度为 h 的斜树，仅有 h 个结点，退化为线性结构，是二叉树的极端情况。

### 📊 🔑 二叉树的核心性质（408 必考公式 + 推导）

> 1️⃣ 性质 1：二叉树第 i 层的结点上限 

**结论**：二叉树的第 $i$ 层（$i\geq1$，根结点为第 1 层），最多有 $2^{i-1}$ 个结点。

推导过程：
> 采用数学归纳法证明：

🔹 基例（$i=1$）： 第 1 层只有根结点，最多有 $1=2^{0}=2^{1-1}$ 个结点，结论成立。
🔸 归纳假设（假设 $i=k$ 时成立）： 假设第 $k$ 层最多有 $2^{k-1}$ 个结点。 
🔺 归纳递推（证明 $i=k+1$ 时成立）： 由于二叉树每个结点最多有 2 个子结点，因此第 $k+1$ 层的最大结点数为： 
$$\text{第}k\text{层最大结点数} \times 2 = 2^{k-1} \times 2 = 2^{k} = 2^{(k+1)-1}$$ 
结论成立。 

---

> 2️⃣ 性质 2：深度为 h 的二叉树的结点上下限 

**结论**：深度为 $h$ 的二叉树，最少有 $h$ 个结点（斜树），最多有 $2^h - 1$ 个结点（满二叉树）。

推导过程：
最少结点数：每层仅 1 个结点，共 $h$ 层，总计 $h$ 个结点。 最多结点数：每一层都达到该层的最大结点数，为等比数列求和：
$$n_{\text{max}}=2^0+2^1+2^2+\dots+2^{h-1}=\frac{2^h - 1}{2-1}=2^h -1$$

---

> 3️⃣ 性质 3：n 个结点的完全二叉树的高度计算 

**结论**：具有 $n$ 个结点的完全二叉树，高度为 $\lceil \log_2(n+1) \rceil$，等价为 $\lfloor \log_2 n \rfloor + 1$（$\lceil \ \rceil$ 为向上取整符号，$\lfloor \ \rfloor$ 为向下取整符号）。 

推导过程： 设完全二叉树的高度为 $h$，根据完全二叉树的定义，总结点数 $n$ 满足不等式： 
$$2^{h-1} \leq n \leq 2^h - 1$$ 

>（1）推导 $h=\lceil \log_2(n+1) \rceil$ 对不等式变形： 

$$2^{h-1} - 1 < n \leq 2^h - 1$$ 
$$2^{h-1} < n+1 \leq 2^h$$
$$h-1 < \log_2(n+1) \leq h$$
由于 $h$ 必须是正整数，因此： 
$$h = \lceil \log_2(n+1) \rceil$$

> （2）推导 $h=\lfloor \log_2 n \rfloor + 1$ 对原不等式变形：

$$2^{h-1} \leq n < 2^h$$ $$h-1 \leq \log_2 n < h$$ 
因此 $h-1 = \lfloor \log_2 n \rfloor$，即：
$$h = \lfloor \log_2 n \rfloor + 1$$ 
  
  ---
  
> 4️⃣ 性质 4：叶子结点与度为 2 的结点的数量关系

**结论**：任意一棵非空二叉树，叶子结点（度为 0）的个数 $n_0$，始终比度为 2 的结点个数 $n_2$ 多 1，即：
$$n_0 = n_2 + 1$$ 
   
推导过程： 设树中总结点数为 $n$，度为 1 的结点个数为 $n_1$，总边数为 $e$。 

>（1）从结点分类角度，总结点数满足：

$$n = n_0 + n_1 + n_2$$ 

>（2）从边数角度，二叉树中除根结点外，每个结点都有且仅有一条来自父结点的边，因此：

$$n = e + 1$$ 
总边数 $e$ 等于所有结点的总度数，因此：
$$e = 0 \times n_0 + 1 \times n_1 + 2 \times n_2 = n_1 + 2n_2$$ 
 联立两式：
$$n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$$ 
化简后得到核心公式：
$$n_0 = n_2 + 1$$ 

---

> 5️⃣ 性质 5：完全二叉树的编号父子对应规则 

**结论**：对完全二叉树从 1 开始，按照**从上到下、从左到右**的层序顺序编号，对任意编号为 $i$ 的结点，有： 
1. 若 $i=1$，为根结点，无父结点；若 $i>1$，其父结点编号为 $\lfloor i/2 \rfloor$。
2. 若 $2i > n$，该结点无左孩子（为叶子结点）；否则左孩子编号为 $2i$。 
3. 若 $2i+1 > n$，该结点无右孩子；否则右孩子编号为 $2i+1$。

**核心意义**：该性质是二叉树顺序存储的核心基础，通过数组下标即可直接计算父子关系，无需额外存储指针。

### 💾 🔑 二叉树的主流存储结构

二叉树存储的核心是**既要保存结点数据，也要保存结点之间的左右父子关系**，主流有两种实现方式，适配不同场景。

#### 1️⃣ 📋 顺序存储（数组实现）

**核心原理**：采用一维数组按**完全二叉树的层序顺序**存储结点，利用性质 5 的数组下标直接体现父子关系，无需额外存储指针。

- 对于完全二叉树：空间利用率 100%，是最优存储方式。
- 对于非完全二叉树：需要预留空结点的数组位置，会造成空间浪费。

**核心特点**：

- ⚡ 找父 / 子结点极快，通过下标直接计算，时间复杂度 O (1)
- ✅ 实现简单，无需处理指针，内存由编译器自动管理
- ❌ 非完全二叉树空间利用率低，深度大、结点少的极端场景会浪费大量空间
- 🎯 适用场景：完全二叉树、堆排序、优先队列等固定结构的场景

---

#### 2️⃣ 🔗 链式存储（二叉链表实现）

**核心原理**：每个结点包含三个部分：数据域 + 左孩子指针 + 右孩子指针，通过指针动态链接结点，按需申请内存。

- 这是二叉树最通用的存储方式，不受树的形态限制。

**核心特点**：

- ✅ 空间利用率高，按需申请内存，无空结点的空间浪费
- ✅ 增删结点灵活，适配任意形态的非完全二叉树
- ❌ 原生结构查父结点需遍历整棵树，时间复杂度 O (n)，可通过添加 parent 指针优化为 O (1)
- ❌ 无法通过下标直接访问结点，必须从根结点开始遍历
- 🎯 适用场景：普通二叉树、二叉搜索树、AVL 树、红黑树等绝大多数树型结构

---

#### 3️⃣ 🔍 补充：为什么普通 n 叉树不使用 n 叉链表存储

普通 n 叉树极少采用固定 n 个指针的 n 叉链表存储，核心原因有两点：

1. **严重的空间浪费**
    
    n 叉链表要求每个结点固定预留 n 个孩子指针，而实际场景中，绝大多数结点的度远小于 n，大量指针处于空置状态。例如度为 3 的树，若大部分结点只有 1 个孩子，每个结点会浪费 2 个指针空间；最坏的斜树场景下，仅有 1/n 的指针被有效利用，空间利用率极低。而孩子兄弟表示法的二叉链表，每个结点仅固定 2 个指针，无额外预留，空间利用率稳定可控。
    
2. **操作与维护极其困难**
    
    n 叉链表的孩子指针以数组形式存储，插入孩子时需要遍历查找空指针位置，删除孩子时需要移动数组元素填补空位，遍历子结点时需要循环 n 个指针判断是否为空，逻辑繁琐且效率低下。而二叉链表仅需处理两个固定指针，插入、删除、遍历的逻辑统一且简洁，可直接复用二叉树的所有成熟算法。

#### 1️⃣ 📋 顺序存储二叉树代码

```cpp
// 顺序存储二叉树（静态数组存储，适用于完全二叉树）
// 核心思想：按完全二叉树的层序遍历顺序存储结点，利用数组下标体现父子关系
//          若父结点下标为 i，则左孩子下标为 2*i，右孩子下标为 2*i+1
// 优点：查父/子结点极快（通过下标直接计算，时间复杂度O(1)），实现简单
// 缺点：对于非完全二叉树，可以使用但空间利用率低（需预留空结点位置）；若树深度大且结点少，浪费大量空间
// 核心操作：建树、查找结点下标、查父结点、查子结点
namespace Sequential_Binary_Tree {
    class BinaryTree {
    public:
        // 构造函数：安全初始化数组，用'\0'作为空结点标记
        BinaryTree() {
            for (char& v : data)
                v = '\0';
        }

        // 析构函数：无需手动实现
        // data为静态数组，内存由编译器自动管理，对象销毁时自动释放，无内存泄漏风险
        void buildTree() {
            int n;
            cin >> n;
            // 输入合法性校验：结点数需在有效范围内
            if (n <= 0 || n >= maxx) {
                cout << "Invalid node count (must be 1~" << maxx - 1 << ")." << endl;
                return;
            }

            char root;
            cin >> root;
            data[1] = root;

            char x, fx;
            bool isRight;
            // 循环构建剩余n-1个结点
            for (int i = 2; i <= n; ++i) {
                cin >> x >> fx >> isRight;
                int j = Find(fx);

                // 父结点存在性校验，不存在则跳过当前结点
                if (j == -1) {
                    cout << "Parent '" << fx << "' not found. Skip node '" << x << "'." << endl;
                    continue;
                }
                // 计算对应孩子的数组下标
                int childIdx = isRight ? 2 * j + 1 : 2 * j;
                // 数组越界校验，避免访问非法内存
                if (childIdx >= maxx) {
                    cout << "Node '" << x << "' out of bounds. Skip." << endl;
                    continue;
                }

                data[childIdx] = x;
            }
        }

        // 查找存储数据x的结点，返回对应数组下标，不存在返回-1
        int Find(char x) {
            // 遍历整个有效数组范围，匹配目标数据
            for (int i = 1; i < maxx; ++i) {
                if (data[i] == x)
                    return i;
            }
            return -1;
        }

        // 查询指定结点x的父结点
        void findFather(char x) {
            int id = Find(x);
            if (id == -1)
                cout << "The data '" << x << "' is not exist." << endl;
            else if (id == 1)
                cout << "The node '" << x << "' is the root node and has no parent." << endl;
            else // 无论左右孩子，整数除法向下取整结果即为父结点下标
                cout << "The parent of the node '" << x << "' is '" << data[id / 2] << "'." << endl;
        }

        // 查询指定结点fx的左右孩子
        void findChild(char fx) {
            int id = Find(fx);
            if (id == -1) {
                cout << "The data '" << fx << "' is not exist." << endl;
                return;
            }

            int left = 2 * id;
            // 左孩子存在性判断
            if (left >= maxx || data[left] == '\0')
                cout << "The data '" << fx << "' has not Left Child." << endl;
            else
                cout << "The Left Child of the data '" << fx << "' is '" << data[left] << "'." << endl;

            int right = 2 * id + 1;
            // 右孩子存在性判断
            if (right >= maxx || data[right] == '\0')
                cout << "The data '" << fx << "' has not Right Child." << endl;
            else
                cout << "The Right Child of the data '" << fx << "' is '" << data[right] << "'." << endl;
        }

    private:
        static constexpr int maxx = 1005; // 类级别编译期常量，定义数组最大长度
        char data[maxx];
    };

    // 测试入口
    void runTest() {
        BinaryTree testTree;
        testTree.buildTree();
        testTree.findFather('a');
        testTree.findChild('a');
    }
}
```

#### 2️⃣ 📋 链式存储二叉树代码

```cpp
// 链式存储二叉树（二叉链表，C++面向对象实现）
// 核心思想：每个结点包含【数据域 + 左孩子指针 + 右孩子指针】，通过指针链接结点
// 优点：空间利用率高（按需申请内存，无空结点浪费），增删结点灵活，适合非完全二叉树
// 缺点：查父结点需遍历整棵树（时间复杂度O(n)），无法通过下标直接访问结点
// 核心操作：建树、查找结点、查子结点、递归释放内存
namespace Linked_Binary_Tree {
    class BinaryTree {
    // 必须先定义类型：
    // C++ 按顺序立即解析函数声明的返回值/形参，仅函数体延迟至类完整定义后解析
    private:
        // BTNode为类内私有嵌套结构体，对外完全不可见，封装性强
        struct BTNode {
            char data;
            BTNode* l;
            BTNode* r;

            // 构造函数：创建结点时自动初始化成员，避免野指针
            BTNode(char c = '\0') : data(c), l(nullptr), r(nullptr) {}
        };
        using BTree = BTNode*; // 类型别名，语义上表示二叉树根指针
        BTree root; // 整棵树的根结点指针

    public:
        // 构造函数：初始化空树
        BinaryTree() : root(nullptr) {}

        // 【必须手写】默认析构仅释放root指针本身，不会递归释放链式结点，必造成内存泄漏
        ~BinaryTree() {
            destroyTree(root);
        }

        // 按输入格式构建二叉树
        void buildTree(void)
        {
            int n;
            cin >> n;
            // 输入合法性校验
            if (n <= 0) {
                cout << "Invalid node count (must be greater than 0)." << endl;
                return;
            }

            char rootData;
            cin >> rootData;
            // 创建根结点
            root = new BTNode(rootData);

            char x, fx;
            bool isRight; // 0-左孩子，1-右孩子
            for (int i = 2; i <= n; i++)
            {
                cin >> x >> fx >> isRight;
                // 查找父结点
                BTNode* parent = Find(fx);
                if (parent == nullptr) {
                    cout << "Parent '" << fx << "' not found. Skip node '" << x << "'." << endl;
                    continue;
                }

                // 创建新结点
                BTNode* newNode = new BTNode(x);
                // 挂载到对应孩子位置
                if (isRight) {
                    // 父结点已有右孩子，提示覆盖
                    if (parent->r != nullptr)
                        cout << "Warning: Right child of '" << fx << "' will be overwritten." << endl;
                    parent->r = newNode;
                }
                else {
                    // 父结点已有左孩子，提示覆盖
                    if (parent->l != nullptr)
                        cout << "Warning: Left child of '" << fx << "' will be overwritten." << endl;
                    parent->l = newNode;
                }
            }
        }

        // 查找数据为x的结点，返回结点指针，不存在返回nullptr
        BTNode* Find(char x)
        {
            return findHelper(root, x);
        }

        // 查询指定结点fx的左右孩子
        void findChild(char fx) 
        {
            BTNode* parent = Find(fx);
            if (parent == nullptr) {
                cout << "The data '" << fx << "' is not exist." << endl;
                return;
            }

            // 左孩子判断
            if (parent->l == nullptr)
                cout << "The data '" << fx << "' has not Left Child." << endl;
            else
                cout << "The Left Child of the data '" << fx << "' is '" << parent->l->data << "'." << endl;

            // 右孩子判断
            if (parent->r == nullptr)
                cout << "The data '" << fx << "' has not Right Child." << endl;
            else
                cout << "The Right Child of the data '" << fx << "' is '" << parent->r->data << "'." << endl;
        }

    private:
        // 私有辅助函数：递归查找当前子树中数据为x的结点
        // 进一步地可以写成 有const 与 无const 2个版本(const BTNode* findHelper(BTree root, char x) const 只读)，对应地 Find 函数也重载成 有const 和 无const 2个版本 以适应不同调用函数需求
        BTNode* findHelper(BTree root, char x)
        {
            if (root == nullptr) return nullptr;
            if (root->data == x) return root;
            // 先递归查找左子树，找到则直接返回
            BTNode* leftRes = findHelper(root->l, x);
            if (leftRes != nullptr) return leftRes;
            // 左子树未找到，递归查找右子树
            return findHelper(root->r, x);
        }

        // 私有辅助函数：后序遍历递归释放整棵树，每步递归形参root表示当前子树的根
        void destroyTree(BTree root)
        {
            if (root == nullptr) return;
            // 必须先释放左右子树，再释放当前结点，避免内存泄漏
            destroyTree(root->l);
            destroyTree(root->r);
            delete root;
        }
    };

    // 【命名空间内而非类内/全局】职责分离：
    // 测试非树核心功能，不污染类public接口；避免全局命名冲突，与当前树实现强绑定
    void runTest() {
        BinaryTree testTree;
        testTree.buildTree();
        testTree.findChild('a');
    }
}
```

| 📌 特性             | 💾 顺序存储                  | 🔗 链式存储（二叉链表）                              |
| :---------------- | :----------------------- | :----------------------------------------- |
| **存储结构**          | 纯顺序存储（静态数组）              | 纯链式存储（动态申请结点）                              |
| ⏱️ **找父 / 子结点效率** | O (1)，通过下标直接计算，极快        | 找孩子 O (1)，原生找父 O (n)，加 parent 指针可优化为 O (1) |
| 📦 **空间利用率**      | 完全二叉树 100%，非完全二叉树极低      | 按需申请，无空结点浪费，利用率高                           |
| ✅ **核心优点**        | 实现简单，无指针操作，内存自动管理，随机访问快  | 适配任意形态二叉树，增删结点灵活，无空间浪费                     |
| ❌ **核心缺点**        | 非完全二叉树空间浪费严重，数组长度固定，扩展性差 | 存在指针开销，原生查父结点效率低，需手动管理内存防止泄漏               |
| 🎯 **核心适用场景**     | 完全二叉树、堆、优先队列             | 普通二叉树、二叉搜索树、红黑树、哈夫曼树等绝大多数场景                |

### 🎯 二叉树的核心应用场景

1. 🔍 **二叉搜索树与平衡树**
    
    二叉排序树、AVL 树、红黑树等核心数据结构，均基于二叉树的有序特性实现，用于高效的查找、插入、删除操作，广泛应用于 STL 的 map/set、数据库索引等场景。
    
2. 📁 **哈夫曼编码与哈夫曼树**
    
    基于二叉树的带权路径长度最优特性，实现数据的无损压缩，广泛应用于文件压缩、音视频编码、通信协议等领域。
    
3. 📝 **表达式树与语法树**
    
    编译原理中，用二叉树存储表达式的运算逻辑、程序的语法结构，实现表达式求值、语法解析、代码生成等核心功能。
    
4. 🧩 **堆与优先队列**
    
    完全二叉树的顺序存储结构是堆的底层实现基础，优先队列广泛应用于任务调度、最短路径、TopK 问题等场景。
    
5. 🌳 **树与森林的转换载体**
    
    通过孩子兄弟表示法，任意普通树与森林都可以转换为唯一对应的二叉树，从而复用二叉树的所有成熟算法，是树结构的核心转换桥梁。

### 📝 核心笔记重点

1. 🔴 **核心本质**：二叉树是特殊的有序树，核心特性是**左右子树的有序性**与**递归性**，哪怕只有一个孩子也必须区分左右，这是与普通树最核心的区别。
2. 🔴 **必考性质**：n0​=n2​+1、完全二叉树的高度计算、编号父子规则是选择题与计算题的高频考点，必须熟记公式与推导过程。
3. 🔴 **存储结构**：顺序存储的核心是利用下标体现父子关系，仅适合完全二叉树；二叉链表是通用存储方式，必须手动实现析构函数递归释放内存，避免内存泄漏。
4. 🔴 **特殊二叉树**：满二叉树是完全二叉树的特例，完全二叉树的特性是 408 高频考点，尤其是度为 1 的结点最多 1 个、叶子结点的分布规则。
5. 🔴 **设计思想**：普通 n 叉树优先使用孩子兄弟表示法转为二叉树存储，而非 n 叉链表，核心是解决空间浪费与操作维护的问题。
