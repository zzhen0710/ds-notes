### 📌 核心定义：什么是树？

**树**是**n (n≥0) 个结点构成的有限集合**，是一种**一对多的非线性数据结构**，核心特性是**递归性**，即 “树中还有树”。

- ❌ **空树**：n=0 时，树中没有任何结点，称为空树。
- ✅ **非空树的核心规则（n>0）**：
    
    1. 🌱 有且仅有一个**根结点（Root）**：没有前驱的特殊结点，是整棵树的起点。
    2. 除根结点外，其余结点可分为**m (m≥0) 个互不相交的有限集**，每个集合本身又是一棵符合定义的树，称为根结点的**子树（SubTree）**。
    
- 🔍 与线性表的核心区别：线性表是「一对一」的线性结构，树是「一对多」的非线性结构；线性表中结点（除首尾）有唯一前驱和唯一后继，树中结点（除根）有唯一前驱，但可拥有 0 个或多个后继。

### 🔑 树的核心术语（408 高频考点）

#### 📍 一、结点相关基础术语

- 🧩 **结点**：树中存储数据元素的基本单元，每个结点包含数据域 + 指向子树的指针域。
- 🌱 **根结点**：整棵树中唯一没有前驱的结点，是树的起点，一棵非空树有且仅有一个根结点。
- 👨 **父结点（双亲结点）**：若一个结点有子树，则该结点是其子树根结点的父结点。
- 👶 **子结点（孩子结点）**：一个结点的子树的根结点，称为该结点的子结点。
- 👬 **兄弟结点**：拥有同一个父结点的结点，互为兄弟结点。
- 👫 **堂兄弟结点**：双亲结点在同一层的结点，互为堂兄弟结点。
- 🧭 **祖先结点**：从根结点到该结点的路径上，所有经过的结点（包括该结点的父结点），都是该结点的祖先结点。
- 🌿 **子孙结点**：一个结点的子树中包含的所有结点（包括直接子结点），都是该结点的子孙结点。
- 🍃 **叶子结点（终端结点）**：度为 0 的结点，即没有任何子结点的结点，是树的末端。
- 🌴 **分支结点（非终端结点）**：度不为 0 的结点，即除叶子结点外的所有结点，负责连接子树。

#### 📏 二、度相关术语

- 📐 **结点的度**：一个结点拥有的**子树的个数**，称为该结点的度。
- 📊 **树的度**：整棵树中，所有结点的度的**最大值**，称为树的度。例如：树中结点最大度为 3，则该树称为 3 叉树。
- ⚠️ 补充易混区分：度为 m 的树 vs m 叉树
    
    - 度为 m 的树：树中**至少有一个结点的度为 m**，且所有结点的度都不超过 m，不能为空树。
    - m 叉树：树中**所有结点的度都不超过 m**，可以是空树，也可以所有结点的度都小于 m。
    

#### 📐 三、层次、深度与高度相关术语

- 📚 **结点的层次**：从根结点开始定义，根结点为**第 1 层**，根的子结点为第 2 层，以此类推（考研 408 默认根为第 1 层，部分教材定义根为第 0 层，需注意区分）。
- ⬇️ **结点的深度**：从根结点到该结点的**路径上的边数 / 层数**，从上往下计数。
- ⬆️ **结点的高度**：从该结点到其最远叶子结点的**路径上的边数 / 层数**，从下往上计数。
- 📏 **树的深度（高度）**：整棵树中结点的最大层次数，称为树的深度 / 高度。

#### 📂 四、树的分类与其他核心概念

- 📋 **有序树**：树中结点的子树有严格的**从左到右的顺序**，调换子树的顺序就会变成一棵全新的树。二叉树是最典型的有序树。
- 🆓 **无序树（自由树）**：树中结点的子树没有顺序要求，调换子树的顺序仍然是同一棵树。
- 🌳🌲 **森林**：m (m≥0) 棵**互不相交的树**构成的集合。
    
    - 🔄 核心转换规则：把一棵树的根结点删除，原根的所有子树就构成了一个森林；反过来，给一个森林添加一个统一的根结点，森林就会变成一棵树。
    
- 🛤️ **路径与路径长度**：树中两个结点之间的路径，是由这两个结点之间的结点序列构成；路径长度是路径上**边的数量**。树中任意两个结点之间有且仅有一条唯一的路径（树无环）。

### 📊 🔑 树的核心性质（408 必考公式 + 推导） 

>1️⃣ 性质 1：结点数与总度数的关系 

结论：树中的结点总数 = 所有结点的总度数 + 1 

推导过程： 
设树中总结点数为 $n$，总边数为 $e$。
除根结点外，每个结点都有且仅有一条来自父结点的边，因此：
								$$n=e+1$$ 
树中每条边都对应一个子结点，总边数 $e$ 等于所有结点的总度数（每个结点的度是它拥有的子结点数，即发出的边数），因此：
								$$e=\text{总度数}$$
联立得最终公式： 
								$$n=\text{总度数}+1$$ 

---

>2️⃣ 性质 2：度为 m 的树的层结点上限 

结论：度为 $m$ 的树，第 $i$ 层（$i\geq1$）最多有 $m^{i-1}$ 个结点。

推导过程：
采用数学归纳法证明： 
🔹 基例（$i=1$）：
第 1 层只有根结点，最多有 $1=m^{0}=m^{1-1}$ 个结点，结论成立。
🔸 归纳假设（假设$i=k$时成立）：
假设第 $k$ 层最多有 $m^{k-1}$ 个结点。 
🔺 归纳递推（证明$i=k+1$时成立）：
由于树的度为 $m$，第 $k$ 层的每个结点最多有 $m$ 个子结点，因此第 $k+1$ 层的最大结点数为：
$$\text{第k层最大结点数} \times m = m^{k-1} \times m = m^{k} = m^{(k+1)-1}$$ 
结论成立。

---

>3️⃣ 性质 3：高度为 h 的 m 叉树的结点上限

结论：高度为 $h$ 的 $m$ 叉树，最多有 $\frac{m^h - 1}{m-1}$ 个结点（满 $m$ 叉树）。

推导过程：
高度为 $h$ 的满 $m$ 叉树，每一层都达到该层的最大结点数（性质 2），因此总结点数是各层最大结点数的等比数列求和：
$$n_{\text{max}}=m^0+m^1+m^2+\dots+m^{h-1}=\frac{m^0 (m^h - 1)}{m-1}=\frac{m^h - 1}{m-1}$$ 
补充：等比数列求和公式 $S_n=\frac{a_1(q^n-1)}{q-1}$，此处首项 $a_1=1$，公比 $q=m$，项数 $n=h$ 

---

>4️⃣ 性质 4：具有 n 个结点的 m 叉树的最小高度

结论：$n$ 个结点的 $m$ 叉树，最小高度为 $\lceil \log_m(n(m-1)+1) \rceil$（$\lceil \ \rceil$ 为向上取整符号）。 

推导过程：
要使高度最小，必须让树的每一层都尽可能填满（即接近满 $m$ 叉树）。
设最小高度为 $h$，则： 
前 $h-1$ 层是完全填满的满 $m$ 叉树，总结点数为：$\frac{m^{h-1} - 1}{m-1}$ 第 $h$ 层至少有 1 个结点，因此总结点数 $n$ 满足不等式： 
$$\frac{m^{h-1} - 1}{m-1} < n \leq \frac{m^h - 1}{m-1}$$ 
右侧不等式变形（求 h 的下限） 
$$ \begin{align*} n &\leq \frac{m^h - 1}{m-1} \\ n(m-1) &\leq m^h - 1 \\ n(m-1)+1 &\leq m^h \\ \log_m(n(m-1)+1) &\leq h \end{align*} $$ 
左侧不等式变形（求 h 的上限）
$$ \begin{align*} \frac{m^{h-1} - 1}{m-1} &< n \\ m^{h-1} - 1 &< n(m-1) \\ m^{h-1} &< n(m-1)+1 \\ h-1 &< \log_m(n(m-1)+1) \end{align*} $$
最终联立结论
$$h-1 < \log_m(n(m-1)+1) \leq h$$ 
由于 $h$ 必须是正整数，因此最小高度为：
$$h = \lceil \log_m(n(m-1)+1) \rceil$$

### 💾 🔑 树的三种主流存储结构

树的存储核心是**既要保存结点数据，也要保存结点之间的父子关系**，主流有三种实现方式，分别适配不同的使用场景。

#### 1️⃣ 📋 双亲表示法（顺序存储实现）

**核心原理**：采用**一维数组**顺序存储树的所有结点，每个结点包含两个部分：

- 数据域：存储结点本身的数据值
- 双亲域：存储该结点的**父结点在数组中的下标**，根结点的双亲域设为 - 1（无父结点）

**核心特点**：

- ⚡ 找父结点极快，时间复杂度 O (1)，直接通过双亲域定位
- 🐢 找子结点较慢，需要遍历整个数组才能找到某个结点的所有子结点，时间复杂度 O (n)
- ✅ 存储结构紧凑，利用数组的连续空间，实现简单

**🎯 适用场景**：频繁查找父结点的场景，如并查集（Disjoint Set Union）的底层实现。

---

#### 2️⃣ 🔗 孩子表示法（顺序 + 链式混合实现）

**核心原理**：结合顺序存储和链式存储，分为两部分：

1. 表头数组：一维数组顺序存储树的所有结点，每个数组元素包含：
    
    - 数据域：存储结点数据
    - 孩子链表头指针：指向该结点的孩子链表的第一个结点
    
2. 孩子链表：每个结点对应一个单链表，链表中存储该结点的**所有子结点在表头数组中的下标**

**核心特点**：

- ⚡ 找子结点极快，直接访问对应结点的孩子链表，无需遍历全表
- 🐢 找父结点较慢，需要遍历所有孩子链表才能找到某个结点的父结点，时间复杂度 O (n)
- ✅ 完美解决了双亲表示法找子结点慢的问题，适合频繁访问子结点的场景

**🎯 适用场景**：树的层次遍历、子树操作等频繁访问子结点的场景。

---

#### 3️⃣ ⭐ 孩子兄弟表示法（二叉树表示法，链式存储实现）

**核心原理**：也叫**左孩子右兄弟表示法**，是树最常用的链式存储方式，每个结点包含三个部分：

- 数据域：存储结点本身的数据值
- 左孩子指针：指向该结点的**第一个子结点**（最左侧的子结点）
- 右兄弟指针：指向该结点的**右侧相邻的兄弟结点**

**本质**：

- 就是把原树 T，通过某种方式 **(根结点保持不变，每个结点的后继变成原树中的长子和右边相邻的亲兄弟------左孩子右兄弟)** 转化成二叉树 T'，以二叉链表的形式存储二叉树

**核心特点**：

- 🔄 万能转换：可以把**任意一棵普通树 / 森林**，转换成唯一对应的二叉树，解决了普通树难以用二叉树操作的问题
- ✅ 操作灵活：可以复用二叉树的所有遍历、操作算法，实现简单
- ⚡ 找子结点方便：通过左孩子指针找到第一个子结点，再通过右兄弟指针遍历所有子结点
- ❌ 原生结构不支持快速找父结点，需额外添加 parent 指针优化
- 🔔 结构设计：为了统一操作，加**头指针**，但**不带头结点**（对于 n 度树，一般不进行频繁删改操作，无需头结点优化）

**🎯 适用场景**：树与二叉树的转换、森林的存储与操作，是考研 408 最常考的树存储结构。

#### 1️⃣ 📋 双亲表示法代码

```c
// 双亲表示法实现普通树（静态数组存储） 
// 核心思想：每个结点仅记录【数据 + 父结点下标】，快速查父、遍历查子 
// 优点：查父结点极快（直接通过父下标访问，时间复杂度O(1)），存储结构紧凑、实现简单 
// 缺点：查子结点效率低（需遍历整个静态数组筛选，时间复杂度O(n)），增删结点需移动数组元素 
// 核心操作：建树、查找结点下标、查父结点、查子结点、插入结点。
namespace Parent_Representation {
	const int maxx = 100;   // 树的最大结点数
	int cur;                // 当前已存入的结点总数（游标）

	// 树结点结构：数据域 + 父结点下标
	struct Node {
		char data;      // 结点数据（字符型）
		int fatherID;   // 父结点在数组中的下标，根结点为 -1
	}p[maxx];

	// 查找数据为 data 的结点，返回数组下标，不存在返回 -1
	int Find(char data)
	{
		// 遍历已存结点，匹配数据
		for (int i = 0; i < cur; i++)
			if (p[i].data == data)
				return i;
		// 未找到对应结点
		return -1;
	}

	// 查询指定结点 x 的父结点
	void findFather(char x)
	{
		// 先找到结点 x 的下标
		int id = Find(x);
		// 结点不存在(n == 0)
		if (id == -1)
			printf("The node '%c' is not exist.\n", x);
		// 是根结点（无父结点）
		else if (p[id].fatherID == -1) // or 根结点固定存在(n > 0)、且固定放在数组下标 0 的位置 id == 0
			printf("The node '%c' is the root node and has no parent.\n", x);
		// 正常输出父结点数据
		else
			printf("The parent of the node '%c' is %c\n", x, p[p[id].fatherID].data);
	}

	// 查询指定结点 fx 的所有子结点
	void findChild(char fx)
	{
		// 先找到父结点 fx 的下标
		int id = Find(fx);
		if (id == -1) {
			printf("The node '%c' is not exist.\n", fx);
			return;
		}
		// 标记：是否找到子结点
		bool hasChild = false;
		printf("The child of the node '%c' is(are) :", fx);
		// 遍历所有结点，筛选父结点为 id 的结点
		for (int j = 0; j < cur; j++)
			if (p[j].fatherID == id) {
				printf(" %c", p[j].data);
				hasChild = true; // 找到子结点，标记为真
			}
		// 如果没有子结点（叶子结点）
		if (!hasChild)
			printf("None.The node '%c' is a leaf node(no children).", fx);
		printf(".\n");
	}

	// 插入新结点 x，父结点为 fx
	void Insert(char x, char fx)
	{
		// 树已满，无法插入
		if (cur == maxx)
			printf("Insertion failed, the tree is full.\n");
		else {
			// 存入新结点数据
			p[cur].data = x;
			// 查找父结点下标并赋值
			p[cur].fatherID = Find(fx);
			// 结点总数 +1
			cur++;
		}
	}

	// 从控制台输入建树（根结点 + n-1 条父子关系）
	void buildTree(void)
	{
		int n;            // 总结点数量
		scanf("%d", &n);
		char root;        // 根结点数据
		scanf(" %c", &root);
		// 初始化根结点：父下标为 -1
		p[0].data = root;
		p[0].fatherID = -1;
		cur++;            // 根结点存入，计数+1

		char x, fx;
		// 循环插入剩余 n-1 个结点
		for (int i = 0; i < n - 1; i++) {
			scanf(" %c %c", &x, &fx);
			Insert(x, fx);
		}
	}

	// 测试入口：建树 + 查询 D 的父结点 + 查询 D 的子结点
	void runTest(void)
	{
		buildTree();
		findFather('D');
		findChild('D');
	}
}
```

#### 2️⃣ 🔗 孩子表示法代码

```c
// 孩子表示法实现普通树（静态数组+孩子链表）
// 核心思想：每个结点仅记录【数据 + 孩子链表头指针】，孩子链表存储所有孩子的下标
// 优点：查子结点极快（直接遍历链表）
// 缺点：原始实现查父结点必须遍历全树（优化后存 parentID 可 O(1) 查父）
// 核心操作：建树、查找结点下标、查父结点、查子结点、插入结点
namespace Child_Representation {
	const int maxx = 100;   // 树的最大结点数
	int cur;                // 当前已存入的结点总数（游标/数组下标）

	// 孩子链表结点结构：存储【孩子结点的数组下标】+ 下一个孩子指针
	typedef struct Node {
		int childID;         // 关键：存储孩子在数组中的下标（不是字符！）
		struct Node* next;   // 指向同一个父结点的下一个孩子
	}ChildNode;

	// 树的【表头结点】结构：存储结点数据 + 孩子链表头指针
	struct Tree {
		char data;           // 结点数据（字符型）
		// 优化：int parentID;  // 优化方案：直接存储父结点下标，让查父从O(n)→O(1)
		ChildNode* first;    // 孩子链表的头指针（指向第一个孩子结点）
	}t[maxx];               // 静态数组存储所有表头结点

	// 功能：查找数据为 x 的结点，返回其在数组中的下标，不存在返回 -1
	int Find(char x)
	{
		for (int i = 0; i < cur; i++) {
			if (t[i].data == x)
				return i;
		}
		return -1;
	}

	// 功能：查询指定结点 x 的父结点
	// 重点：原始孩子表示法无父指针，必须遍历【所有结点的孩子链表】匹配
	void findParent(char x)
	{
		int id = Find(x);
		if (id == -1)
			printf("The node '%c' is not exist.\n", x);

		// 优化（替换注释下方代码）：
		// 优化原理：直接读取父结点下标，O(1) 访问，无需遍历
		/*
		else if (t[id].parentID == -1)
			printf("The node '%c' is the root node and has no parent.\n", x);
		else
			printf("The parent of the node '%c' is %c\n", x, t[t[id].parentID].data);
		*/
		else {
			// 遍历所有表头结点，检查它的孩子链表是否包含目标结点
			for (int i = 0; i < cur; i++) {
				ChildNode* p = t[i].first;  // 每次取当前结点的孩子链表
				while (p != NULL)
				{
					// 找到：当前链表结点存储的孩子下标 == 目标结点下标
					if (p->childID == id) {
						printf("The parent of the node '%c' is %c.\n", x, t[i].data);
						return;
					}
					p = p->next;  // 正确：先判断再移动，避免空指针访问
				}
			}
			// 遍历完所有链表都没找到，说明是根结点
			printf("The node '%c' is the root node and has no parent.\n", x);
		}
	}

	// 功能：查询指定结点 fx 的所有子结点
	// 重点：孩子表示法核心优势，直接遍历该结点的孩子链表即可
	void findChild(char fx)
	{
		int id = Find(fx);
		if (id == -1)
			printf("The node '%c' is not exist.\n", fx);
		else {
			ChildNode* p = t[id].first;  // 正确：取【目标结点自身】的孩子链表
			// 孩子链表为空 → 叶子结点
			if (p == NULL)
				printf("This node '%c' is a leaf node and has no children.\n", fx);
			else
			{
				printf("The child of the node '%c' is(are) :", fx);
				// 正确：先打印数据，再移动指针，不会漏掉第一个孩子
				while (p != NULL)
				{
					printf(" %c", t[p->childID].data);
					p = p->next;
				}
				printf(".\n");
			}
		}
	}

	// 功能：插入新结点 x，其父结点为 fx（头插法）
	// 重点：头插法标准写法，避免空指针崩溃
	void Insert(char x, char fx)
	{
		// 树已满，无法插入
		if (cur == maxx) {
			printf("Insertion failed, the tree is full.\n");
			return;
		}
		// 1. 新结点存入数组
		t[cur].data = x;
		t[cur].first = NULL;

		// 2. 查找父结点下标
		int id = Find(fx);
		// 优化：t[cur].parentID = id;  // 优化：记录父结点下标

		// 3. 创建孩子链表结点
		ChildNode* s = (ChildNode*)malloc(sizeof(ChildNode));
		s->childID = cur;        // 存储新结点在数组中的下标

		// 头插法（标准写法）
		// 错误点：写 t[id].first->next = s，会导致空指针崩溃（first本身就是一个"next"指针）
		s->next = t[id].first;   // 新结点指向原头结点
		t[id].first = s;         // 头指针指向新结点

		cur++;  // 结点总数+1
	}

	// 功能：从控制台输入建树（格式：结点总数 + 根结点 + n-1 组父子关系）
	void buildTree(void)
	{
		int n;
		scanf("%d", &n);
		char root;
		scanf(" %c", &root);

		// 初始化根结点
		t[0].data = root;
		t[0].first = NULL;
		// 优化：t[0].parentID = -1;  // 根结点无父结点，下标记为-1
		cur = 1;  // 根结点存入，游标从1开始

		char x, fx;
		// 循环插入剩余 n-1 个结点
		for (int i = 1; i < n; i++) {
			scanf(" %c %c", &x, &fx);
			Insert(x, fx);
		}
	}

	// 测试入口：建树 + 查询D的子结点 + 查询D的父结点
	void runTest(void)
	{
		buildTree();
		findChild('D');
		findParent('D');
	}
}
```

#### 3️⃣ 🌿 孩子兄弟表示法代码

```c
// 孩子兄弟表示法实现普通树（纯链式存储 / 左孩子右兄弟表示法）
// 核心思想：每个结点记录【数据 + 第一个孩子指针 + 右兄弟指针】，将普通树转化为二叉树存储
// 优点：通用性极强，可将任意树/森林转为二叉树，复用二叉树算法；查找孩子高效
// 缺点：原生结构**不支持快速查找父结点**，遍历效率极低；如需快速查父需额外添加 parent 指针
// 结构设计：纯链表实现，仅设头指针，不带头结点（n 度树极少频繁删改，无需头结点优化）
// 核心操作：初始化、建树、查找结点、插入结点、查找子结点
namespace Child_Sibling_Representation {
	// 完全链表，不会满，不需要maxx和cur判满
	typedef struct Node {
		char data;           // 结点数据域
		struct Node* son;    // 左孩子指针：指向当前结点的第一个子结点
		struct Node* bro;    // 右兄弟指针：指向当前结点的右侧相邻兄弟
	}Node, * TreeList;

	// 功能：递归查找数据为 fx 的结点（孩子兄弟表示法专用）
	// 遍历规则：优先递归遍历【子结点树】，子树遍历完再递归遍历【兄弟结点链】
	// 查找情况说明：
	// 1. 当前结点数据 == 目标数据 → 找到，直接返回当前结点
	// 2. 当前结点有子结点 → 递归进入子结点树查找，找到则立即返回结果
	// 3. 当前结点无儿子/子树未找到 → 递归进入右侧兄弟结点继续查找
	// 4. 遍历完子结点+兄弟结点均未找到 → 返回 NULL
	// 缺点：本结构无 parent 指针，只能从上向下查找，无法向上回溯查找父结点
	Node* Find(TreeList root, char fx)
	{
		// 情况1：当前结点就是目标结点，直接返回
		if (root->data == fx)
			return root;

		Node* ans = NULL;

		// 情况2：当前结点有子结点，递归遍历子结点树
		if (root->son != NULL) {
			ans = Find(root->son, fx);
			if (ans != NULL)    // 子树中找到，直接返回
				return ans;
		}

		// 情况3：子树未找到，递归遍历右侧兄弟结点
		if (root->bro != NULL) {
			ans = Find(root->bro, fx);
			if (ans != NULL)    // 兄弟链中找到，直接返回
				return ans;
		}

		// 情况4：所有路径都遍历完，未找到目标结点
		return NULL;
	}

	// 功能：插入新结点 x，其父结点为 fx（尾插法插入兄弟链表）
	// 返回：根结点（根永远不变，返回用于统一接口风格）
	TreeList Insert(TreeList root, char x, char fx)
	{
		Node* p = Find(root, fx);
		if (p == NULL) {
			printf("The node '%c' is not exist.\n", fx);
			return root;
		}

		// 创建新结点
		Node* s = (Node*)malloc(sizeof(Node));
		s->data = x;
		s->son = NULL;
		s->bro = NULL;

		// 父结点尚无孩子，直接作为第一个孩子
		if (p->son == NULL)
			p->son = s;
		// 已有孩子，插到孩子的最后一个兄弟的后面
		else {
			p = p->son;
			while (p->bro != NULL) {
				p = p->bro;
			}
			p->bro = s;
		}

		// 从树角度来说需要返回(插入后树变了),从根结点角度来说不需要返回(根结点始终不变)
		return root;
	}

	// 功能：初始化一棵只有根结点的树
	// 返回：根结点指针
	TreeList initTree(char x)
	{
		TreeList root = (TreeList)malloc(sizeof(Node));
		root->data = x;
		root->son = NULL;
		root->bro = NULL;

		return root;
	}

	// 功能：根据输入构建孩子兄弟表示法的树
	// 返回：整棵树的根结点
	TreeList buildTree(void)
	{
		int n;
		scanf("%d", &n);
		char r;
		scanf(" %c", &r);
		TreeList root = initTree(r);

		char x, fx;// 原树的数据x，和父结点数据fx
		for (int i = 1; i < n; i++) {
			scanf(" %c %c", &x, &fx);
			root = Insert(root, x, fx);
		}
		return root;
	}

	// 功能：查找指定结点 fx 的所有孩子（遍历孩子 + 兄弟链）
	// 注意：本结构**未实现查找父结点**，原生结构不支持向上查询
	void findSon(TreeList root, char fx)
	{
		Node* p = Find(root, fx);
		if (p == NULL) {
			printf("The node '%c' is not exist.\n", fx);
			return;
		}

		// 无孩子 → 叶子结点
		if (p->son == NULL)
			printf("This node '%c' is a leaf node and has no children.\n", fx);
		else {
			p = p->son;
			printf("The child of the node '%c' is(are) :", fx);
			while (p) {
				printf(" %c", p->data);
				p = p->bro;
			}
			printf(".\n");
		}
	}

	// 测试入口：建树 + 查询 D 的子结点
	void runTest(void)
	{
		Node* root = buildTree();
		findSon(root, 'D');
	}
}
```

### ⚖️ 三种存储结构对比总结

|📌 特性|💾 双亲表示法|🔗 孩子表示法|🌿 孩子兄弟表示法|
|:--|:--|:--|:--|
|**存储结构**|纯顺序存储（数组）|顺序 + 链式混合存储|纯链式存储（二叉链表）|
|⏱️ **找父结点效率**|O (1)，极快|O (n)，很慢，(优化后O(1))|O (n)，原生结构慢，加 parent 指针可优化|
|⚡ **找子结点效率**|O (n)，很慢|O (1) 访问链表头，遍历子结点极快|O (k)，k 为子结点个数，遍历灵活|
|✅ **核心优点**|结构简单，存储紧凑，找父结点高效|找子结点高效，空间利用率高|可转换为二叉树，复用二叉树算法，通用性最强|
|❌ **核心缺点**|找子结点效率低，增删结点需移动数组元素|找父结点效率低，链表结构有额外指针开销|原生结构找父结点不便，有指针开销|
|🎯 **核心适用场景**|并查集、频繁找父结点的场景|频繁访问子结点、层次遍历场景|树与二叉树转换、森林操作、考研核心考点|

### 🎯 树的核心应用场景

1. 📁 **文件系统目录结构**
    
    操作系统中的文件 / 文件夹目录，是树结构最典型的应用。文件夹是分支结点，文件是叶子结点，支持嵌套子目录（子树）。
    
2. 🌳 **二叉树与搜索树的基础**
    
    二叉树是特殊的有序树，二叉排序树、AVL 树、红黑树、B 树 / B + 树等核心数据结构，都是基于树的基础特性扩展而来。
    
3. 🔒 **哈夫曼编码与哈夫曼树**
    
    基于树的带权路径长度最优特性，实现数据的无损压缩，广泛应用于文件压缩、音视频编码领域。
    
4. 🔗 **并查集（DSU）**
    
    基于树的双亲表示法实现，用于解决集合的合并与查找问题，应用于图的连通性判断、最小生成树算法等场景。
    
5. 📝 **表达式树与语法树**
    
    编译原理中，用树结构存储表达式的运算逻辑、程序的语法结构，实现表达式求值、语法解析。
