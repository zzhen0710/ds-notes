## 📌 交换类排序核心总述 🧩

核心思想：**比较相邻 / 区间内元素，逆序则交换**，通过不断交换逆序对逐步消除乱序，最终得到升序数组。

两大典型实现：冒泡排序、快速排序；其中冒泡为基础简单交换排序，快速排序是工程级高性能分治交换排序。

交换类排序共性：通过交换完成逆序修正，快速排序是实际开发首选，冒泡仅适合教学演示。

## 一、基础交换排序：冒泡排序 Bubble Sort 🫧

### 1. 名称由来拓展说明 💡

之所以命名 “冒泡”：每一轮遍历乱序区间时，**最大的未排序元素会像气泡一样，逐步通过相邻交换 “浮” 到乱序区间末尾**，每趟结束后末尾新增一块有序区，气泡上浮的视觉效果是命名来源。

### 2. 完整执行逻辑 🚶

>📍 冒泡排序完整趟数演示图

![交换类排序 1.png](<../pict/交换类排序 1.png>)

1. 初始状态：整个数组全部为乱序区，有序区长度为 0
2. 共最多执行 n−1 趟遍历，每趟规则：
    
    ① 从左到右遍历当前乱序区间，两两相邻对比 `data[j]`、`data[j+1]`
    
    ② 若前数 > 后数，二者交换，把大数向右推移
    
    ③ 一趟遍历结束，当前乱序区间最大值上浮至区间最右端，有序区向右扩张 1 位
3. 提前终止优化：设置交换标记 `has_swap`，若某一趟全程无任何交换，代表数组已经全局有序，直接跳出外层循环，减少无效遍历。

### 3. 复杂度与稳定性总结 📊

- 最好时间复杂度：$O(n)$（数组完全有序，仅 1 趟遍历后直接退出）
- 最坏、平均时间复杂度：$O(n^2)$（完全逆序数组，每趟全部相邻元素交换）
- 空间复杂度：$O(1)$，原地排序，仅常数标记变量
- 稳定性：**稳定排序**，仅相邻逆序才交换，相等元素不会互换位置，相对顺序不变

### 4. C++ 完整封装源码（带提前终止优化）💻

```cpp
// ---------- 第二类：交换类排序 ----------
void BubbleSort::Sort() {
    // 获取数组长度
    int n = static_cast<int>(data_.size());

    // 外层循环：i为无序区间右边界，每轮冒泡后末尾i个元素已有序
    for (int i = n; i >= 1; i--) {
        bool has_swap = false; // 优化：标记本轮是否发生交换
        // 内层遍历无序区间，相邻元素逆序则交换
        for (int j = 1; j < i; j++) {
            if (data_[j] < data_[j - 1]) {
                std::swap(data_[j], data_[j - 1]);
                has_swap = true;
            }
        }
        // 本轮无任何交换，数组全局有序，直接结束全部排序
        if (!has_swap) break;
        // 输出当前轮次数组快照
        PrintStep(n + 1 - i);
    }
}
```

## 二、高性能交换排序：快速排序 Quick Sort ⚡

### 1. 核心分治思想 💡

基于**分而治之**思路，区别于冒泡逐次交换相邻元素，快排通过基准值一次性批量划分区间：

1. 在待排序区间 `[l, r]` 选定基准值 `pivot`
2. 双指针相向扫描分区：小于基准的全部挪到区间左侧，大于基准的全部挪到区间右侧
3. 基准归位到它的最终有序下标，此时基准左侧所有元素 ≤ 基准，右侧所有元素 ≥ 基准
4. 递归对基准左、右两个子区间重复分区操作，直到区间长度 ≤1（天然有序）

>📍 快速排序分区趟数演示图

![交换类排序 2.png](<../pict/交换类排序 2.png>)

### 2. 基准选取方案与双指针细节拆解

#### 三种主流基准选取方式

1. 取区间左端点 `pivot = data_[l]`（本次代码实现方案）
2. 取区间右端点 `pivot = data_[r]`
3. 三数取中法：取区间左端、右端、中间三者中位数，规避有序数组导致最坏复杂度

#### 双指针先动右指针的关键原因

基准存放在左端点，先让右指针`j`向左扫描找小于基准的值；两指针相遇时，相遇位置元素一定 ≤ 基准，和左端点基准交换后，天然保证左区间全部≤基准、右区间全部≥基准，不会破坏分区逻辑。

### 3. 复杂度与稳定性总结 📊

- 最好、平均时间复杂度：$O(nlogn)$，二分均匀划分，递归深度为 $logn$
- 最坏时间复杂度：$O(n^2)$（数组完全有序 / 逆序，基准极端不均衡，退化为单分支递归）
- 空间复杂度：$O(logn)∼O(n)$，递归调用栈开销，均衡分区栈深 $logn$，最坏栈深 $n$
- 稳定性：**不稳定排序**，分区交换会跨位置打乱相等元素原始先后顺序

### 4. C++ 完整递归封装源码（左基准双指针分区）💻

```cpp
void QuickSort::Sort() {
    // 获取数组长度
    int n = static_cast<int>(data_.size());
    int step = 0; // 全局分区轮次计数器，记录已完成的分区轮数
    // 启动递归快排，区间 [0, n-1]
    quick(0, n - 1, step);
}

void QuickSort::quick(int l, int r, int& step) noexcept {
    // -------------------------- 递归终止条件 --------------------------
    // 区间左边界 ≥ 右边界：区间为空或仅剩1个元素，天然有序，直接退出
    if (l >= r) return;

    // -------------------------- 初始化基准与双指针 --------------------------
    int pivot = data_[l]; // 选取区间最左侧元素作为基准值
    int i = l, j = r;     // 初始化左右双指针：i从左端点出发，j从右端点出发

    // -------------------------- 双指针相向分区扫描 --------------------------
    // 循环目标：将小于基准的元素移到左区，大于基准的元素移到右区
    while (i < j) {
        // 【右指针先动】j 从右往左，找到第一个小于基准的元素
        // 先动j的原因：保证i、j最终相遇时，指向的元素 ≤ 基准值
        // 后续和左基准交换后，才能保证左区全≤基准、右区全≥基准
        while (i < j && data_[j] >= pivot) j--;

        // 【左指针后动】i 从左往右，找到第一个大于基准的元素
        // 带等号是为了跳过和基准相等的元素，避免重复元素导致死循环
        while (i < j && data_[i] <= pivot) i++;

        // 两指针未相遇时，交换找到的大小元素：小的挪去左区，大的挪去右区
        if (i < j) std::swap(data_[i], data_[j]);
    }

    // -------------------------- 基准归位 --------------------------
    // 此时 i == j，该位置就是基准的最终排序位置
    // 交换左端点基准与相遇位置元素，交换后：左区元素均 ≤ 基准，右区元素均 ≥ 基准
    std::swap(data_[l], data_[i]);
    int mid = i; // 记录基准的最终下标，用于拆分左右子区间

    // -------------------------- 打印本轮分区结果 --------------------------
    // 每完成1次基准归位算1轮排序，轮次+1后打印当前数组状态
    PrintStep(++step);

    // -------------------------- 分治递归 --------------------------
    // 分别对基准左侧、右侧的子区间递归执行快速排序
    quick(l, mid - 1, step);
    quick(mid + 1, r, step);
}
```

### 5. C++ std::sort () 底层拓展补充 📌

`std::sort()` 并非单纯快速排序，是**混合排序算法**，工程上结合三种排序优势：

1. 主体框架： introsort（内省排序），以快速排序为核心递归划分；
2. 小规模子区间优化：当子数组长度小于阈值（通常 16），切换为**直接插入排序**（小数组插入排序常数开销更小）；
3. 递归深度超限兜底：若快排递归深度超过 $2logn$，直接切换为**堆排序**，规避最坏情况 $O(n^2)$ 时间复杂度与栈溢出。
    
    整体保证最坏时间复杂度稳定为 $O(nlogn)$，是工业级通用排序函数。
