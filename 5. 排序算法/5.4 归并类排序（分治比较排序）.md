## 🏷️ 归并排序总览🧩

归并排序为**二路分治稳定比较排序**，核心思想：分治拆分 + 有序序列合并，全局时间复杂度恒为 $O(nlogn)$，不受原始数据有序程度影响，是唯一稳定、最坏复杂度无退化的比较排序。

- 对应知识点：
1. 二分递归拆分：数组从中间均分，左右子区间递归排序；单元素区间天然有序，递归终止。
2. 双指针合并：两个有序序列通过双指针比较合并，合并完成后写回原数组对应位置。
3. 复杂度：最优 / 平均 / 最坏均为 $O(nlogn)$，需临时数组，非就地排序。

## 一、完整算法原理拆解📖

### 1. 分阶段（递归拆分）

1. 取区间中点 `mid = left + (right-left)/2`，规避数值溢出；
2. 递归处理左区间 `[left, mid]`、右区间 `[mid+1, right]`；
3. 递归终止条件：`left >= right`，区间仅存单个元素，无需排序。

### 2. 治阶段（有序合并）

1. 双指针 `i`（左序列起点）、`j`（右序列起点）遍历两个有序子区间；
2. 每次取更小值存入临时数组，`<=` 保证相等元素相对顺序不变（稳定性）；
3. 某一子序列遍历完毕后，直接追加另一序列全部剩余元素；
4. 将临时数组合并完成的有序区间拷贝回原数组对应下标。

## 二、C++ 完整源码（仅微调注释，源码无修改）

```cpp
// ==============================================================
// 第四类：归并排序 🧩（2路分治归并实现，时间复杂度O(nlogn)、稳定、非就地排序）
// ==============================================================
/// 归并排序（自顶向下递归版，严格遵循2路归并分治规则✨）
export class MergeSort : public SortBase {
public:
    using SortBase::SortBase;
    void Sort() override;

private:
    /// 递归分治：对闭区间 [left, right] 执行2路归并排序
    /// @param tmp 全局复用的临时数组，避免递归内重复申请内存，合并结果先存入这里再拷回原位置
    /// @param step 轮次计数器，引用传递跨递归层共享
    void mergeSort(int left, int right, std::vector<int>& tmp, int& step) noexcept;

    /// 合并两个有序子区间：左区间 [left, mid] + 右区间 [mid+1, right]
    /// 合并规则：双指针i/j分别遍历两个有序序列，每次取较小值放入临时数组；某一子序列遍历完毕后，直接追加另一子序列剩余全部元素，最终有序序列放回原数组对应位置
    void merge(int left, int mid, int right, std::vector<int>& tmp) noexcept;
};

// ---------- 归并排序主逻辑 ----------
void MergeSort::Sort() {
    int n = static_cast<int>(data_.size());

    std::vector<int> tmp(n); // 预先申请全局临时数组，全程复用，减少内存分配开销；合并阶段必须借助临时空间，因此归并不是就地排序
    int step = 0;             // 排序轮次计数器
    mergeSort(0, n - 1, tmp, step);
}

void MergeSort::mergeSort(int left, int right, std::vector<int>& tmp, int& step) noexcept {
    if (left >= right) return; // 递归终止条件：序列只剩一个元素时天然有序，无需额外排序操作✅

    // 计算区间中点：用 left + (right-left)/2 写法，避免 left+right 数值溢出，完成2路均分拆分
    int mid = left + (right - left) / 2;

    // 「分」：递归拆分区间，分别对左右两个均分后的子区间递归执行归并排序
    mergeSort(left, mid, tmp, step);
    mergeSort(mid + 1, right, tmp, step);

    // 「治/归并」：将两个已经有序的子区间合并为一个完整的有序区间
    merge(left, mid, right, tmp);

    // 每完成一次合并打印一轮结果，与其他排序轮次逻辑对齐
    PrintStep(++step);
}

void MergeSort::merge(int left, int mid, int right, std::vector<int>& tmp) noexcept {
    int i = left;    // 左有序子序列遍历起始指针
    int j = mid + 1; // 右有序子序列遍历起始指针
    int k = left;    // 临时数组有序结果写入指针

    // 双指针遍历阶段：枚举比较两个子序列当前元素，将更小的元素优先写入临时数组
    while (i <= mid && j <= right) {
        if (data_[i] <= data_[j]) { // "<=" 保留相等元素原有先后顺序，保障排序稳定性
            tmp[k++] = data_[i++];
        }
        else {
            tmp[k++] = data_[j++];
        }
    }

    // 左子序列还有剩余未遍历元素时，直接批量追加到临时数组尾部
    while (i <= mid) {
        tmp[k++] = data_[i++];
    }

    // 右子序列还有剩余未遍历元素时，直接批量追加到临时数组尾部
    while (j <= right) {
        tmp[k++] = data_[j++];
    }

    // 合并完成的有序序列必须放回原数组对应的区间位置，完成本轮排序更新
    for (int p = left; p <= right; ++p) {
        data_[p] = tmp[p];
    }
}
```

## 三、核心特性总结📊

- ⏱️ 时间复杂度：最优 / 平均 / 最坏 $O(nlogn)$，无最坏退化场景
- 📦 空间复杂度：$O(n)$，全局临时数组开销
- ✅ 稳定排序 | ❌ 非就地排序
- 适用场景：大数据稳定排序、外部排序、桶排序桶内排序子算法
