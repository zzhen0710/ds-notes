## 📌 前置统一概念：有序区 & 乱序区 🧩

绝大多数简单排序算法都会把数组划分为两大区域：

1. ✅ **有序区**：初始仅包含数组第一个元素，排序过程持续向右扩张，最终覆盖整个数组
2. ⚪ **乱序区**：初始覆盖全部剩余元素，排序过程持续收缩，最终长度归零

插入类排序核心逻辑：**逐个取出乱序区首元素，向前插入到有序区的合法位置**，依靠不断扩大有序区间完成全局升序。

原生直接插入、折半插入、2 路插入均为**稳定排序**，相等元素相对位置不会交换 🤝；希尔排序为不稳定排序。

## 一、基础版：直接插入排序 Straight Insertion Sort 📎

### 1. 完整执行流程 🚶

>📍 直接插入排序完整趟数演示图

![插入类排序 3.png](<../pict/插入类排序 3.png>)

1. 初始状态：有序区`[1,1]`，乱序区`[2,n]`，共执行 `n-1` 趟排序
2. 每趟操作固定三步：
    
    ① 缓存乱序区第一个元素`temp = a[i]`
    
    ② 倒序向前遍历有序区，凡是大于`temp`的元素统一向后移位，同步腾出空位
    
    ③ 将缓存值`temp`填入空位`j+1`，有序区右边界 + 1
3. 循环执行至乱序区清空，数组整体有序

### 2. 倒序遍历合并移位操作的核心优点 ⚡

拆分式思路：先遍历查找插入位置 → 再单独循环批量后移元素；

代码中将两步合并为同一个`while`循环，优势：

- ⚡ 仅单次遍历有序区间，减少一层循环开销，降低数组读写次数
- 🧠 无需额外记录插入下标，遍历、移位同步完成，代码逻辑高度紧凑
- 📉 最坏、平均场景均能减少循环执行次数，精简代码行数

### 3. 完整 C++ 源码（注释优化，不改动核心逻辑）💻

```cpp
// ---------- 第一类：插入类排序 ----------
void StraightInsertionSort::Sort() {
    // 获取数组长度
    int n = static_cast<int>(data_.size());
    // 🎯 i从下标1开始：数组第0个元素天然构成初始有序区
    for (int i = 1; i < n; ++i) {
        int temp = data_[i]; // 📦 缓存当前待插入的乱序区首元素
        int j = i - 1;
        // 🔄 向前倒序遍历有序区间，大于temp的元素全部统一后移1位
        while (j >= 0 && data_[j] > temp) {
            data_[j + 1] = data_[j];
            j--;
        }
        // 📍 j+1 是temp的合法插入空位，回填完成单趟插入
        data_[j + 1] = temp;
        PrintStep(i); // 🖨️ 打印当前趟排序后的数组状态
    }
}
```

### 4. 两种基础优化方案（常数优化，不改变时间复杂度量级）🔧

#### 🧮 折半插入排序

优化底层逻辑拆解：

1. 原直接插入采用**线性倒序遍历**查找插入位置，每查找一次最坏需要遍历全部有序区，查找开销 $O(n)$；
2. 折半插入将查找环节替换为二分查找，利用有序区间单调性，查找开销压缩至 $O(logn)$；
3. 二分仅定位插入下标，**元素后移操作无法优化**，找到位置后仍需要批量挪动后方所有元素，移位开销依旧 $O(n)$。
    
    短板：整体最坏 / 平均时间复杂度依旧 $O(n^2)$，仅降低查找循环常数，复杂度量级无变化。

#### 🔁 2 - 路插入排序

>📍 2 路插入循环辅助数组示意图

![插入类排序 1.png](<../pict/插入类排序 1.png>)

优化底层逻辑拆解：

1. 开辟环形循环辅助数组`d[]`存放有序元素，以数组中点作为分界；
2. 待插入元素分两类处理：比中点值小的向前头插，比中点值大的向后尾插，大幅减少大范围批量后移的场景；
3. 辅助数组为环形结构，头尾无缝衔接，避免数组扩容、整体平移。
    
    短板：完全逆序的极端最坏场景下，移位次数无任何减少，时间复杂度仍为平方级，无法突破 $O(n^2)$。

## 二、进阶优化：希尔排序 Shell Sort（缩小增量排序）🔬

### 1. 核心设计思想 💡

>📍 希尔排序多增量分组演示图

![插入类排序 4.png](<../pict/插入类排序 4.png>)

依托直接插入排序两大天然特性：**小规模数组插入排序效率极高**、**接近有序的数组插入排序速度大幅提升**

1. 设定增量`d`，将数组按下标间隔`d`分组，每组独立执行直接插入排序
2. 每轮分组排序完成后，增量折半缩小 `d = d / 2`，重复分组插入流程
3. 最终增量`d=1`，等价于全局直接插入排序；此时数组已高度有序，插入排序开销极低

### 2. `for (int i = d; i < n; ++i)` 循环设计巧妙之处 ✨

常规直接插入排序`i=1`，希尔排序`i`从`d`起步，底层逻辑拆解：

- 每组内下标`0、d、2d...`，每组第一个元素下标`0`天然有序，无需参与比较
- `i=d`是每组第二个元素，是每组第一个需要向前对比、插入的元素
- `i`持续自增遍历全部剩余元素，一次性遍历所有分组，无需嵌套多层分组循环，代码极度简洁
- 统一用`j = i - d`定位同组前一个元素，复用一套插入逻辑，统一处理所有分组

### 3. 希尔排序不稳定原理图解

>📍 希尔排序不稳定原理示意图

![插入类排序 2.png](<../pict/插入类排序 2.png>)

图中数组：`[3, 2, 2*, 4]`，带`*`标记的`2*`与普通`2`为相等元素，初始相对顺序：`2`在前、`2*`在后

1. 若当前增量`d=2`，分组为`[3, 2*]`、`[2, 4]`；
2. 第一组执行插入排序时，`2* < 3`，二者交换位置；
3. 交换后数组变为`[2*, 2, 3, 4]`，相等元素`2`与`2*`原始相对顺序颠倒；
4. 核心结论：相等元素若被划分至不同分组，跨组交换会破坏原有先后顺序，因此希尔排序**不稳定**；只有当两个相等元素始终被分到同一分组时，才会保持稳定。

### 4. 完整 C++ 源码（注释优化，不改动核心逻辑）💻

```cpp
// ---------- 第一类：插入类排序 ----------
void ShellSort::Sort() {
    // 获取数组长度
    int n = static_cast<int>(data_.size());
    // 📝 记录希尔排序增量轮次，用于逐轮打印排序状态
    int iter = 0;

    // 🔁 外层循环：控制增量d，初始为数组一半，每次折半缩小，直到增量为1（全局直接插入排序）
    for (int d = n / 2; d >= 1; d /= 2) {
        // 🧩 中层循环：以当前增量d分组，对每组分别执行插入排序
        // ✨ i从d开始，每组第一个元素天然有序，从第二个元素开始向前比较插入
        for (int i = d; i < n; ++i) {
            // 📦 取出当前待插入的分组元素
            int temp = data_[i];
            // 🎯 j定位到同组前一个元素，间隔固定为d
            int j = i - d;
            // 🔄 内层循环：同组内元素后移，比temp大的元素统一向后挪d位
            while (j >= 0 && data_[j] > temp) {
                data_[j + d] = data_[j];
                j -= d;
            }
            // 📍 找到插入位置j+d，将temp回填，完成本组单趟插入
            data_[j + d] = temp;
        }
        // 🖨️ 当前增量下所有分组排序完成，打印本轮完整数组状态
        PrintStep(++iter);
    }
}
```

### 5. 优化层级区分：希尔排序 vs 两种基础插入优化 📏

1. 折半插入、2 路插入：仅**常数级优化**，仅减少查找 / 移位的循环次数，最坏、平均时间复杂度依旧是 $O(n^2)$，**时间复杂度量级无改变**。
2. 希尔排序：通过多轮分组预排序，提前消除大规模逆序对，平均时间复杂度达到 $O(n^{1.3})$，**直接改变时间复杂度的数量级**，性能远优于原生直接插入排序。

### 6. 复杂度与特性总结 📊

- 最好时间复杂度：$O(n)$（数组完全有序，仅外层增量循环）
- 最坏时间复杂度：$O(n^2)$（极差增量序列）；平均时间复杂度：$O(n^{1.3})$
- 空间复杂度：$O(1)$，原地排序，无需额外数组
- 稳定性：**不稳定排序**，分组交换会打乱相等元素相对顺序
